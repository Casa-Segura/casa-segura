# CS-083 — Persist embeddings via sentence-transformers MiniLM pipeline

## Context

Semantic search embeddings must align with multilingual MiniLM (**384 dims**, cosine-ready) described in [[PRD_F3_CORPUS_Y_RAG]] §US-02 and [[DOMAIN_MODEL]]. Embeddings derive from **`text_paraphrased`** only ([[PRD_F3_CORPUS_Y_RAG]] BR-02).

## Scope

**In:**

- Offline batch embedding using `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`, CPU default with optional CUDA via env vars from PRD (`EMBEDDING_DEVICE`, `EMBEDDING_BATCH_SIZE`).
- Implement tokenizer truncation honoring **≤512 transformer tokens** (~first 512 tokens) with explicit logging when truncation fires (WARN per chunk ID hash).
- Validate vector norms ~1 via numeric tolerance asserting model normalization semantics.
- Write vectors into `LEGAL_CHUNK.embedding` with pgvector `(384)` type; ensure cosine distance operator compatibility.
- Respect cache directory configurable (`EMBEDDING_MODEL_CACHE_DIR`).

**Out:**

- Live query-time embedding server separate from ingestion worker (reuse same helper module though).

## Acceptance criteria

- [ ] Golden test: fixture sentence yields embedding vector length **exactly 384** and finite elements.
- [ ] Given mocked model output, truncation path triggers when injecting >512-token synthetic paraphrase (length measured using model tokenizer utilities).
- [ ] Embedding job records processing duration metrics (hook for [[EPIC-11-observability]] later).
- [ ] Forbidden path test: ingestion fails if engineer attempts embedding `text_verbatim` instead of paraphrase in pipeline (contract test on function parameter names / dataclass constraints).

### BVA — boundary value analysis

| Token length | Boundary | Expected |
|---|---|---|
| Paraphrase token count | 511 / 512 / 513 | truncation only beyond policy threshold |

## Test intent (Rule 9)

Tests guard BR-02 — switching embedding text source to verbatim must fail, since it breaks curated semantic alignment assumptions.

## Status — 2026-05-16

Audit against commit `d613c2d`.

**Implemented:**

- `embed_texts(texts, batch_size=None) -> list[list[float]]` and `embed_query(text) -> list[float]` in `backend/corpus/application/embeddings.py`.
- `get_embedding_model()` lazy-loads `SentenceTransformer(settings.EMBEDDING_MODEL, device=settings.EMBEDDING_DEVICE)` as a process-wide singleton guarded by `_model_lock`.
- Defaults from settings: `EMBEDDING_MODEL=paraphrase-multilingual-MiniLM-L12-v2`, `EMBEDDING_DEVICE=cpu`, `EMBEDDING_BATCH_SIZE=32`. Normalised embeddings (`normalize_embeddings=True`) so cosine distance is well-defined.
- `EMBEDDING_DIM = 384` constant exported for callers that need to allocate zero vectors.
- Truncation detection: logs `embeddings.truncating` with the count when any input exceeds `model.max_seq_length * 4` characters (rough lower-bound, since tokenizer charges ~4 chars/token).
- `torch` and `sentence-transformers` added to `pyproject.toml` runtime deps.
- `embed_query("")` returns a zero vector (no model call) to keep callers safe for empty inputs.

**Partial / Missing (gap vs PRD AC):**

- AC1 (golden 384-dim test with finite elements): not exercised by `tests/test_corpus_*` — would require a live model download, deferred to integration. **Action**: add a fast unit test that monkeypatches `get_embedding_model` to assert shape contract.
- AC2 (truncation triggers at >512 tokens): the heuristic is character-based, not tokenizer-based. PRD wants the tokenizer to detect truncation. The model **does** truncate internally; we just don't measure it precisely. Test missing.
- AC3 (processing-duration metric): not implemented — relies on the ingestion CLI's wrapping (CS-084) which doesn't emit a `embeddings_seconds` histogram yet.
- AC4 (contract test: ingestion must embed `text_paraphrased`, NOT `text_verbatim`): structurally enforced in `ingest_corpus.py:147` (`texts = [draft.text_paraphrased for _, draft in drafts]`), but no `pytest` assertion locks it. **Action**: snapshot test that introspects `texts` source.

**Status:** `in_progress` — pipeline works locally; CI-friendly tests + duration metric pending.

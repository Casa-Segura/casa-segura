# CS-351 — Manual project verification form fallback (UI + API validation)

## Context

When vision extraction is unreliable (“panic button” R1[[ARCHITECTURE]] §6), users must proceed via **manual form** fields aligning with billboard extraction outputs. EPIC mandates OCR failure gracefully routes here without implying contract upload is next.

## Scope

**In:**
- Frontend route gated by [[CS-356]] exposing fields: developer, project, permit, address (localized labels ES)
- Server-side validators mirroring client (length limits, trimming, Unicode normalization parity with contract project slug rules where feasible)
- State machine UX: surfaced after OCR enum `failure|low_confidence|timeout`

**Out (explicit):**
- Contract upload on same wizard step (explicit post-message CTA only on results page[[CS-355]])
- Persisting partially filled drafts server-side beyond ephemeral session TTL

## Acceptance criteria

- [ ] From OCR failure toast/modal user opens form with fields prefilled wherever partial structured data existed
- [ ] Submit reaches backend DTO reused by downstream checks (`ProjectVerificationInput`), independent of OCR path
- [ ] Accessible form semantics (keyboard order, validation messaging) referencing [[EPIC-10]] eventual pattern library when available
- [ ] Telemetry event `fallback=manual_form` increments without embedding typed address strings in logs

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| Permit field | empty vs whitespace-only | rejected with localized error |
| Field length | at max chars vs overflow | server rejects with same code as FE |
| `PROJECT_VERIFICATION_ENABLED` | toggled mid-session | new navigations obey flag without silent 500 |

## Test intent (Rule 9)

Encodes resilience promise from [[STATUS]] R1: OCR degradation must **not strand** users—blocking happens only on explicit validation gaps, never on refusal to analyze contracts.

## Notes

- Contract analysis disclaimers enforced separately via [[CS-337]]; form should still hint informational nature consistent with roadmap voice.

# CS-155 — Applicability filtering and intra-category weight renormalization

## Context

Criteria excluded for a contract type **must not** participate as zeros — they are omitted entirely ([[RUBRICA_CONTRATO]] §3). Within each category, printed weights in §16 are shares that must **renormalize** over the applicable subset only ([[RUBRICA_CONTRATO]] §10).

## Scope

**In:**
- Applicability predicate: `contract_type in criterion.applicable_types` using canonical enum set from [[PRD_GENERAL]] US-02
- Per-category weight normalization audit trail in `CategoryScore`: expose `criteria_count_total`, `criteria_count_applicable`, `criteria_count_unverifiable` ([[PRD_F4_MOTOR_RUBRICA]] §5.4)
- Assertion helper for QA: \(\sum_{i \in A} w_i' = 1\) where \(w_i' = w_i / \sum_{j\in A} w_j\) for applicable set \(A\)

**Out (explicit):**
- Contract type classification — [[EPIC-04-classification]]
- Global category renormalization — already in [[CS-152]] (ensure no double scaling)

## Acceptance criteria

- [ ] Given type `CVC`, criteria that apply only to financed purchases (e.g. **B2**) are **absent** from inputs to category aggregation, not present with score 0
- [ ] Given type `CVP` with one criterion manually flagged N/A incorrectly in seed data, validation suite catches weight sum drift vs rubric appendix [[RUBRICA_CONTRATO]] §16
- [ ] Given applicable subset A within category B, computed effective weights satisfy \(\sum w_i' = 1.0 \pm 10^{-9}\)
- [ ] Given `NOT_CLASSIFIABLE` upstream analysis terminates before scoring — document interaction with pipeline `not_analyzable` (no partial category averages)

### BVA — boundary value analysis

| Scenario | Boundary | Expected |
|---|---|---|
| All criteria in cat apply | none excluded | weights equal nominal proportions |
| Exactly one criterion applies | singleton | category score equals that criterion score |
| Empty category applicability | zero rows | category omitted from global combine ([[CS-152]]) |
| ARC vs ARV | differing subsets | golden diff fixtures |

## Test intent (Rule 9)

Renormalization bugs skew scores **most** when exotic types drop half of category B — property tests must shake relative proportions, not only CVP defaults ([[EPIC-06-rubric-engine]] risk R-06-3).

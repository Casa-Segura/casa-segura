# CS-245 — Public report route with TTL enforcement and anti-caching headers

## Context

`GET /r/{public_short_id}` is the capability URL for ephemeral HTML rendition ([[PRD_F7_ENTREGA_MULTICANAL]] §3 US-04). TTL defaults **30 days** from lifecycle policy ([[STATUS_RECONCILIATION]] BVA linkage, [[PRD_F7_ENTREGA_MULTICANAL]] §4 BR-06).

## Scope

**In:**
- Django REST Framework view resolving analysis by short id string
- When `NOW() < link_expires_at` AND lifecycle state is not flagged expired by cron semantics: delegate HTML synthesis to regeneration port [[CS-247]]
- Attach headers `X-Robots-Tag: noindex, nofollow`, `Cache-Control: no-store`, HSTS directive per §7 sample
- Guarantee **no persisted HTML** intermediary violating [[PRD_GENERAL]] BR-01 (no shared Redis HTML snapshot across requests in MVP)

**Out (explicit):**
- Visit analytics / per-link counters (contradicts **no tracking** posture in segment brief — **do not implement** PRD draft line about anonymous visit counters)
- Authentication layer (capability token only)

## Acceptance criteria

- [ ] Given valid id pre-expiration, response `200` with `Content-Type: text/html; charset=utf-8` and body byte-identical to `generate_report_html` output for same instant snapshot (modulo explicitly allowed volatile fields documented in CS-208)
- [ ] Given unknown id, returns `404` HTML page copy per §7 "Análisis no encontrado" without leaking whether id format valid
- [ ] Given post-expiration, routes to handler specified in [[CS-246]] returning `410 Gone` (preferred) or `200` soft page per final API table — **implement PRD §7.1 410 for expired** unless product revises
- [ ] Response headers on success include `no-store` to prevent CDN retention

### BVA — boundary value analysis

| Clock vs `link_expires_at` | Boundary | Expected |
|---|---|---|
| Δt = -1 ms | still valid | HTML 200 |
| Δt = 0 vs +1 ms | inclusive/exclusive | Treat `link_expires_at <= NOW()` as expired (use UTC-aware wall-clock compare) |
| Entropy | malformed id | same 404 body as missing to avoid enumeration |

## Test intent (Rule 9)

Caching headers accidentally allowing downstream retention breaks privacy promise more surely than wrong font — assert `Cache-Control` absence of `public`.

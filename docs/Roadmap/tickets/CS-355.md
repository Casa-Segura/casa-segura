# CS-355 — Project verification results page + optional contract-analysis CTA

## Context

After [[CS-354]], users need a concise **results** surface reflecting band, rationale bullets, reputation/permit notices, plus **explicit optional** encouragement to analyze a contract—without gating ([[STATUS_RECONCILIATION]], [[EPIC-12]]). Disclaimer language must originate from [[CS-337]].

## Scope

**In:**
- Mobile-first page rendering verdict DTO and structured rationale keys localized ES
- **Optional CTA** deep-linking to standalone contract ingestion route (same product, no prerequisite session/token)
- Surfaces disclaimers pulled from disclaimer registry constants (never ad‑hoc literals)
- Copy clarifying billboard info was **not** cross-verified against registries unless future feature says otherwise ([[PRD_GENERAL]] BR‑12 analogous transparency)

**Out (explicit):**
- Forcing navigation into contract wizard
- Persisting billboard snapshot thumbnails

## Acceptance criteria

- [ ] Rendering snapshot tests cover `{green,yellow,red}` palettes + iconography consistent with main product semantics
- [ ] CTA present but dismissible/skippable—contract route reachable from global nav unaffected by unfinished project check
- [ ] Footer/header include registry-backed disclaimer substring required by BR‑07
- [ ] Page documents data freshness for reputation snippets when adapter returned evidence (timestamp bounded)

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| CTA impressions | user closes tab before click vs follows link | telemetry `cta_impression_without_nav` permissible; no retries spam |
| Verdict enum | transitions between sessions | SSR HTML encodes canonical enum string casing |
| Feature flag combo | verification on + registry missing | fails build/deploy check (imports must resolve) |

## Test intent (Rule 9)

Guarantees the optional UX line never regresses into a **silent gate**: removing skip affordance or auto-redirect shall fail interaction tests asserting independence from contract ingestion.

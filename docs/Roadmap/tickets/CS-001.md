# CS-001 — Initialize public repo with MIT license and README skeleton

## Context

Casa Segura is open source from day 0 ([[ARCHITECTURE]] §9). The repo's existence and posture is the trust contract — every downstream ticket assumes a public repo with a known posture. This ticket creates that surface.

## Scope

**In:**
- Public GitHub repo under an org (decide org name in [[STATUS]] open questions if not already chosen)
- MIT LICENSE file
- README.md skeleton: what, why, scope (El Salvador only), disclaimer block, contributing pointer, link to PRDs once they move into repo
- `.gitignore` for Python and Node

**Out (explicit):**
- CI configuration — [[CS-004]]
- Code scaffolds — [[CS-002]], [[CS-003]]
- Security disclosure document — [[CS-335]]

## Acceptance criteria

- [ ] Repo URL is public and resolvable without auth
- [ ] LICENSE file is exactly MIT, copyright line names the org and year
- [ ] README opens with: project name, one-sentence purpose, "no es asesoría legal" disclaimer block, link to PRDs
- [ ] `.gitignore` covers `.env`, `__pycache__`, `node_modules`, `.next`, `dist`, `*.pyc`
- [ ] First commit signed if commit-signing is the team policy (decide and document)

## Test intent (Rule 9)

The disclaimer block in the README is a load-bearing element of the product's legal posture per [[PRD_GENERAL]] BR-07. A test (visual review at minimum) must catch its removal in any future commit.

# CS-158 — Criterion evaluator framework (registry, dispatch, concurrency)

## Context

Each of the **38** criteria executes as its own LLM invocation with structured JSON (`temperature≈0.1`, per-call timeout **30s**, concurrency cap **8**, **one retry**) ([[PRD_F4_MOTOR_RUBRICA]] US-01, BR-06–BR-08). Catalog prompts live in `Criterion` rows ([[CS-033]]); runtime code registers Python handlers or templates keyed by `criterion_id`.

## Scope

**In:**
- Async dispatcher loading active `RubricVersion` criteria from DB for `contract_type`
- Registry mapping `criterion_id → evaluator callable`
- Shared middleware: inject contract text, `elements_detected`, economic summary JSON, enforce JSON schema output, map to [[CS-150]] models
- Concurrency semaphore + global watchdog aligning with **60s** analysis budget ([[PRD_F4_MOTOR_RUBRICA]] BR-09)
- Evidence snippet length enforcement ≤500 before persistence ([[PRD_F4_MOTOR_RUBRICA]] BR-16)

**Out (explicit):**
- Full criterion prompt prose — seeded via [[CS-033]] content ops
- OpenRouter credentials — [[EPIC-00-foundation]]
- F3 retrieval — wired in finding enrichment path ([[CS-159]]+ may call helper)

## Acceptance criteria

- [ ] Given 32 applicable criteria, dispatcher launches max **8** concurrent LLM requests (observable via mock concurrency tracker)
- [ ] Given a criterion completes in 31s twice, row is marked `unverifiable` per timeout policy ([[PRD_F4_MOTOR_RUBRICA]] US-01)
- [ ] Given malformed JSON from model after retry, criterion marked `unverifiable` with logged parser error
- [ ] Given evaluation success, output includes `criterion_id`, `score`, `unverifiable`, `override_triggered`, `evidence_snippet`/`None`
- [ ] Given unknown `criterion_id` in registry for active rubric version, startup health check fails fast

### BVA — boundary value analysis

| Parameter | Boundary | Expected |
|---|---|---|
| Concurrency | 8 vs 9 simultaneous | hard cap at 8 |
| Timeout | 30.0s vs 30.1s mock | second classified timeout |
| Retry count | 1 extra attempt | exactly two tries max |
| evidence len | 500 vs 501 chars | truncation |

## Test intent (Rule 9)

Dispatcher behavior determines **SLA breach rate**; tests fix concurrency semantics because raising default above **8** violates approved BR-08 unless product revises PRD.

# CS-230 — Define delivery Pydantic schemas and enums

## Context

Outbound delivery crosses queue workers and HTTP adapters; shared types eliminate drift vs SQL constraints ([[PRD_F7_ENTREGA_MULTICANAL]] §5.1–5.3, [[DOMAIN_MODEL]] §4.3). Canonical channels are **`email_pdf`**, **`whatsapp_summary`**, **`web_link`** aligned with enums in PRD.

## Scope

**In:**
- Python `Enum`/`Literal` equivalents for channels + delivery row statuses `{queued,sending,delivered,failed,expired}` (+ error classification enums `transient|permanent` per §3 US-06 narrative)
- Pydantic request/response payloads for enqueue, webhook callbacks, retry metadata (`attempt_count`, `max_attempts`, `next_attempt_not_before`)
- Serialization helpers hashing targets without logging raw values ([[STATUS_RECONCILIATION]] risk R-08-4 echo)
- Compatibility matrix documenting nullable fields when `channel=web_link` (avoid storing destination) reconciling schema evolution vs privacy promise

**Out (explicit):**
- SMTP / Zavu clients (later tickets)
- Database migrations altering columns (assume [[EPIC-01-persistence]] baseline [[CS-029]] exposes `DeliveryRequest` models)

## Acceptance criteria

- [ ] Mapping table checked into tests enumerates PostgreSQL CHECK constraints ⇄ pydantic enums with exact string literals (failure on typo)
- [ ] Serialization round-trip of sample `DeliveryRequest` ORM row → pydantic DTO hides secrets (`target_value_encrypted` flagged `exclude=True` default)
- [ ] Attempt to instantiate illegal tuple (`channel='sms'`) raises validation error surfaced to caller with stable `error_code`

### BVA — boundary value analysis

| Field | Boundary | Expected |
|---|---|---|
| `attempt_count` vs `max_attempts` | `0≤attempt≤max` vs `attempt>max` | Valid DTO forbids enqueue when `attempt_count>=max_attempts` unless operator override path |
| Channel | `web_link` vs destination-bearing | Presence validators require `target_hash` only when channel expects PII hashing |

## Test intent (Rule 9)

Mismatched enums between DB and pydantic manifests as zombie queue jobs that never transition — tests lock string equality to PRD, not incidental Python Enum auto values.

## Notes

- Coordinate with migrations if schema uses extra columns (`is_resend`, `parent_delivery_request_id`) from §5.1 SQL vs DOMAIN snapshot — prefer PRD DDL when discrepant (**formal PRDs win per [[STATUS_RECONCILIATION]]** preamble)

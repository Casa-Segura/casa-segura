# CS-026 — Schema: LegalDocument + LegalChunk + CorpusVersion

## Context

The legal corpus is curated, versioned, and retrieved with pgvector ([[DOMAIN_MODEL]] §3.4–3.6; [[BE-SERVICES]] §4.6). This ticket creates catalog tables with FK order: `corpus_version` → `legal_document` → `legal_chunk`; `legal_chunk.embedding` dimension **384** must match `EMBEDDING_DIM` default.

## Scope

**In:**
- Tables per PRD DDL: `corpus_version`, `legal_document`, `legal_chunk` with composite PKs/UNIQUEs `(law_id, corpus_version)` and `(corpus_version, law_id, anchor)`
- `VECTOR(384) NOT NULL` on `legal_chunk.embedding`; tags + relevance GIN indexes **defined here or coordinated with [[CS-030]]** (must exist before ingestion load tests)
- `severity_hint` CHECK per PRD DDL
- ORM models + hybrid properties if needed for vector type (pgvector SQLAlchemy typing)

**Out (explicit):**
- Ingestion pipeline scripts — [[EPIC-03-corpus-rag]]
- Similarity queries — feature services; only schema + minimal sanity query in tests

## Acceptance criteria

- [ ] Given migration applied, when inserting `corpus_version` then `legal_document` then `legal_chunk`, when vector literal of dim 384 inserted, then round-trip fetch succeeds
- [ ] Given dim mismatch attempt (383- or 385-length), when insert attempted, then Postgres rejects
- [ ] Given ON DELETE CASCADE from document to chunk per PRD, when parent removed, when chunks existed, then chunks delete (if PRD specifies CASCADE—follow PRD DDL exactly)
- [ ] Given `tags` empty default, when omitted on insert, then stored as `{}` not NULL violating NOT NULL
- [ ] Given uniqueness on anchor triple, when duplicate anchor insert, then UNIQUE constraint triggers

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| Similarity threshold (runtime) | 0.649 vs 0.651 | Not enforced in DB; documented for [[EPIC-03-corpus-rag]] retrieval ([[STATUS_RECONCILIATION]] BVA) |
| `corpus_version.is_active` | partial unique index | Only one active row allowed per PRD DDL—verify migration includes partial unique index |

## Test intent (Rule 9)

Vector dimension drift relative to MiniLM bricks the entire RAG layer. Tests must fail if embedding column width or extension changes without coordinated migration.

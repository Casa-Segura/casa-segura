# CS-290 — Build mobile-first landing page (contract analysis value prop)

## Context

The public web app needs a credible entry that states what [[PRD_GENERAL]] does—analyze a **real estate contract** before signing—not optional project/billboard verification. [[EPIC-10-frontend]] requires a one-sentence value proposition and clear CTA. Visual tone follows [[UI-UX Documents/UI-UX]] §1–2; **copy must not imply** that billboard verification is required before contract upload ([[STATUS_RECONCILIATION]] delta #1).

## Scope

**In:**
- Next.js (App Router) landing route, single column, max-width per [[UI-UX Documents/UI-UX]] (~480px)
- Hero: concise Spanish **tú** register; CTA navigates to upload flow
- Footer includes disclaimer string via [[CS-297]] component (or stub hook if 297 lands same sprint—coordinate)
- Uses design tokens from UI-UX (background, text, accent)

**Out (explicit):**
- Billboard / “Flow 1” capture screens from [[UI-UX Documents/UI-UX]] §3 Screens 2–4 (deferred to [[EPIC-12-project-verification]] if ever built)
- Blog/legal long-form pages

## Acceptance criteria

- [x] Given a visitor on a 360px-wide viewport, when the page loads, then headline, CTA, and footer disclaimer are fully visible without horizontal scroll
- [x] Given the primary CTA, when clicked, then user reaches contract upload route implemented under [[CS-291]] (relative path documented in PR)
- [x] Given readable text audit, when reviewed, then voice is **tú**, not *usted*, and avoids promising material/registry verification beyond PRD
- [x] Given footer renders, when inspected, then it includes the literal disclaimer **"Esto no es asesoría legal"** (sourced from single module per [[CS-297]] once available)
- [x] Given Lighthouse or axe spot-check (manual acceptable for MVP), when run, then primary text/background contrast meets WCAG AA for body copy

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| Viewport width | **360px** | No clipped tap targets; CTA ≥44px tall ([[UI-UX Documents/UI-UX]] §6) |
| Viewport width | 768px+ | Layout stays single-column unless future breakpoint ticket adds desktop grid (explicitly out) |
| CTA label | Spanish | No mixed-language UI strings on landing |

## Test intent (Rule 9)

The landing page is the top-of-funnel **truth contract** for what the product does. Tests must fail if copy reintroduces mandatory billboard verification or *usted* tone inconsistent with [[PRD_GENERAL]] §2.

# CS-353 — Pluggable reputation provider interface (optional, env gated)

## Context

Historical architecture contemplated web searches for reputational snippets[[ARCHITECTURE]] §5. Formal contract PRDs **exclude** broad reputation surfacing[[PRD_GENERAL]] §2, but EPIC‑12 remains an auxiliary flow; **provider-pluggable lookup if configured** is explicit DoD[[EPIC-12]].

## Scope

**In:**
- `ReputationProvider` protocol: `lookup(developer_slug, project_slug) -> ReputationEvidence[]` sanitized (titles/urls truncated, bounded count)
- **Environment gate**: when `PROJECT_REPUTATION_PROVIDER=none`/unset, facade returns typed `skipped_disabled` marker for [[CS-354]]
- Alternate adapter stub for configurable HTTP provider with timeouts, SSRF defenses (allow-listed hosts/domains registry)
- Responses never persisted to Postgres beyond ephemeral cache TTL ≤24h and **never** correlated to contract submissions

**Out (explicit):**
- Default shipping configuration that secretly enables scraping prod without review
- Correlation IDs linking reputation fetch to hashed delivery targets

## Acceptance criteria

- [ ] Compile-time/registry listing enumerates adapters; prod config validation fails unknown keys
- [ ] SSRF protections: rejects private IP ranges on HTTP adapter outbound
- [ ] Telemetry counts `reputation_queries_total{outcome=skipped_disabled|success|failure}` sans query strings containing developer names ([[CS-330]] hygiene policy)
- [ ] Unit tests simulate provider outage → structured partial evidence + note on result page pathway

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| `PROJECT_REPUTATION_PROVIDER` | unset vs synthetic vs http | deterministic branch labels |
| HTTP timeout | T-Δ vs expired | degrade with non-fatal note |
| URL host allowlist | match vs subdomain trick | denied |
| Result count | MAX vs overflow | truncated deterministically |

## Test intent (Rule 9)

Ensures reputational augmentation stays **additive** — disabling env must reproduce identical core verdict flow sans external calls, guarding against covert dependencies.

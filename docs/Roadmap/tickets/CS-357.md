# CS-357 — Reconcile Zavu webhook events with `DeliveryRequest`

## Context

Zavu signs callbacks with `X-Zavu-Signature` using **`ZAVU_WEBHOOK_SECRET`**. Outbound sends use **`ZAVUDEV_API_KEY`**. Webhooks may arrive after API ack; reconciliation keeps **`DeliveryRequest.status`** aligned without logging raw destinations ([[EPIC-08-multichannel-delivery]] DoD).

## Scope

**In:**
- Parse webhook JSON (`type`, nested `data.message.id`)
- Lookup `DeliveryRequest` by **`provider_message_id`**
- Idempotent transitions: `message.delivered` → `delivered`; `message.failed` → `failed` (no downgrade after terminal delivered without product review)

**Out (explicit):**
- SMS provider callbacks — [[CS-242]]

## Acceptance criteria

- [ ] Integration test: signed webhook updates matching row by `provider_message_id`
- [ ] Duplicate `delivered` events do not error
- [ ] Logs contain **event type + delivery_request id + message id** only (no raw JSON body)

## Notes

- Endpoint: **`POST /api/v1/webhooks/zavu/`** — see `delivery/interfaces/api/views.py`.

# CS-160 — Category B evaluators (B1–B9)

## Context

Category **B** (30% global) encodes economic health: down payment, APR, term, total cost, monthly payment ratio, itemized charges, late interest base, prepayment fee, unilateral modification ([[RUBRICA_CONTRATO]] §5). **B7** ties to override **art_12_lpc**; **B9** ties to **art_13_lpc**. Benchmark-facing criteria compose with [[CS-153]] asymmetric clamp.

## Scope

**In:**
- Evaluators `B1`…`B9` wired to `EconomicSummary` + raw contract text for qualitative clauses (B6, B7, B9)
- Numeric scoring ladders exactly as §5 tables using configured benchmark snapshot IDs from [[CS-130]]
- Late-interest computation base classification feeding **art_12_lpc** when total-balance wording detected

**Out (explicit):**

- [ ] Given APR **18%** EAR vs reference **9%**, B2 yields score **2** (14–19% severe band) absent computation-base override ([[RUBRICA_CONTRATO]] B2)

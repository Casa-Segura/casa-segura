# CS-164 — Category F evaluators (F1–F5) plus finding citation wiring

## Context

Category **F** (5% global) covers transparency: Spanish legibility, exhibits, withdrawal communication, total cost clarity, EAR disclosure ([[RUBRICA_CONTRATO]] §9). It closes the **38-criterion** set and is the natural integration point to batch **F3 `retrieve_legal_basis`** calls for every emitted finding before persistence ([[PRD_F4_MOTOR_RUBRICA]] US-03; [[PRD_F3_CORPUS_Y_RAG]] retrieval contract).

## Scope

**In:**
- Evaluators `F1`…`F5` honoring narrower applicability (F3 distance/off-premises; F4/F5 financed types)
- Post-evaluation pass: for each finding with `should_emit_finding=true`, call F3 with `corpus_version`, `threshold=0.65`, `top_k≤5`, populate ≤3 `LegalReference` objects ([[PRD_F3_CORPUS_Y_RAG]] US-03)
- Tagging rules when empty retrieval: `unverifiable_legal` vs `market_based` per [[PRD_F4_MOTOR_RUBRICA]] US-03

**Out (explicit):**
- Rendering citations in PDF — [[EPIC-07-report-generation]]
- Corpus ingestion — [[CS-080]]

## Acceptance criteria

- [ ] Given illegible micro-font clause fixture, F1 scores **0**
- [ ] Given missing critical exhibit reference, F2 scores **0** when rubric classifies exhibit as critical ([[RUBRICA_CONTRATO]] F2)
- [ ] Given distant/off-premises contract without withdrawal communication, rubric criterion **F3** (right of withdrawal) scores **0**
- [ ] Given financed contract omitting stated total cost, F4 scores **0**
- [ ] Given emitted finding and stubbed F3 returning ≥1 chunk above threshold, `Finding.legal_basis` non-empty and each reference traceable to retrieval log id ([[EPIC-03-corpus-rag]] traceability)
- [ ] Given F3 empty list, `legal_basis=[]` and tag applied — **no** synthetic article strings

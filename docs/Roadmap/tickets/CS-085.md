# CS-085 — Implement retrieve_for_finding / retrieve_legal_basis service

## Context

Findings consume curated citations through an internal retrieval API ([[BE-SERVICES]] `retrieve_for_finding`, [[PRD_F3_CORPUS_Y_RAG]] §6.1). Default behavior: pgvector cosine similarity on MiniLM embeddings, filter by thresholds, obey **cite-or-stay-silent** ([[PRD_GENERAL]] BR-02–BR-03 shadow).

## Scope

**In:**

- Python service class (`LegalCitationService`) exposing `retrieve_legal_basis(...) -> list[LegalReference]` with parameters: `finding_text`, `corpus_version` (supports `latest_active` alias resolving to pinned row via [[CS-090]]), `top_k` default **5** per PRD US-03, `threshold` default **0.65**, optional `filter_tags`, `filter_law_ids`, `prefer_anchors` list for criterion-guided narrowing ([[PRD_F3_CORPUS_Y_RAG]] BR-07).
- Embedding query text with identical model weights as ingestion ([[CS-083]] reuse).
- Vector SQL using pgvector cosine distance `<=>` tuned for **descending similarity** semantics; leverage HNSW index from CS-030.
- Hybrid exact patterns from PRD §6.2 regex set; when matched, retrieve chunk `(law_id, article_number)` with synthetic similarity **= 1.0** short-circuiting vector ordering.
- Return empty list **without fallback** when no candidate ≥ threshold (PRD F3 BR-01 cite-or-stay-silent discipline).
- Optional debug structured logging hook writing **hashed queries** feeding [[CS-089]] metrics persistence.

**Out:**

- Public internet exposure (internal/protected QA endpoint optional per §7.1 with auth epic).

## Acceptance criteria

- [ ] Integration test inserts synthetic vectors with orthogonal vs parallel orientation verifying known ranking order reproducibly.
- [ ] Given seeded chunk similarities manual set (SQL fixture) at **0.649 / 0.650 / 0.651**, when threshold default `.650`, only **≥0.650** chunks returned — exact comparator semantics encoded + documented (see BVA).
- [ ] Given `top_k=3` but five candidates surpass threshold, return **three highest** similarities stable tie-break `(law_id, anchor)` lex order.
- [ ] Given regex detectable textual anchor `Art. 4 Ley de Inquilinato` present in synthetic finding string, retrieval returns deterministic chunk irrespective of poorer vector neighbors (score=1 semantics).
- [ ] Given queries with filtering tags narrowing to zero hits pre-vector, yields empty list gracefully (logged).

### BVA — boundary value analysis

| Control | Boundary | Expected |
|---|---|---|
| Threshold (t = 0.65) | similarities 0.649 / 0.650 / 0.651 | **Strict GE:** include `.650`/`.651`, exclude `.649` unless threshold lowered intentionally |
| top_k | 0 vs 1 vs 5 | `top_k` must clamp to ≥1 in API validation (reject 0); k larger than qualifying set returns fewer |
| Corpus version alias | resolves `latest_active` missing | deterministic error surfaced |

## Test intent (Rule 9)

Focus tests on **threshold comparator + top-k stability** — the product promise “no weak citations” fails if inclusivity leaks at float boundary.

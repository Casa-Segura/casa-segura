# CS-354 — Project verification verdict synthesis (green / yellow / red)

## Context

Billboard/manual path must synthesize **simple verdict** analogous to consumer-friendly bands ([[ARCHITECTURE]] §5: “Returns a verdict…”). Bands align numerically with contract UX (**green 8–10**, **yellow 5–7.9**, **red 0–4.9** per [[PRD_GENERAL]] US‑03), applied here to a distilled internal **0–10 heuristic** before mapping to `{green,yellow,red}`.

## Scope

**In:**
- Deterministic scoring function combining permit-format signal, optional reputation evidence weight (skipped path when provider disabled[[CS-353]]), OCR confidence degradation penalties
- Optional LLM **narration only** behind `PROJECT_VERIFICATION_LLM_SYNTH` (default `false` unless product explicitly enables after guardrail review); narrative never overrides deterministic band selection
- Output DTO `{ band, rationale_keys[], heuristic_score}` consumable by [[CS-355]]
- Override table: documented conditions that force **red** (e.g., `format_suspicious` plus corroborating risk flags)

**Out (explicit):**
- 38‑criterion rubric parity with [[EPIC-06-rubric-engine]]
- Claims of legal validity or registry confirmation

## Acceptance criteria

- [x] Deterministic scorer + override table exercised via enumerated pytest fixtures/BVA (`backend/tests/test_project_verification_verdict.py`, `backend/project_verification/domain/verdict_synthesis.py`).
- [x] Reputation transitions (`success` ⇄ `skipped_disabled`) preserve monotonic downgrade expectations documented inline in tests / synthesis comments.
- [x] Exported JSON Schema artifact validates verdict enums **`green | yellow | red`** only (`backend/project_verification/schemas/project_verification_verdict.v1.schema.json`).
- [x] LLM narration surface ships behind `PROJECT_VERIFICATION_LLM_SYNTH` via `narration_only_llm_maybe` (**default/no-op deterministic path**) so production cannot silently override heuristic bands pending product review hook-up.

### BVA — boundary value analysis (verdict enum transitions)

| Input | Boundary | Expected |
|---|---|---|
| heuristic_score | 8.0 vs 7.99 | green ↔ yellow boundary per US‑03 bands |
| heuristic_score | 5.0 vs 4.99 | yellow ↔ red boundary per US‑03 bands |
| Reputation skipped | baseline score ~7.2 without negative signals | stays yellow absent other downward penalties |
| Permit `format_unknown` + high OCR confidence | heuristic mid-range | policy caps at yellow (never auto‑green documented constant `MAX_BAND_UNKNOWN_PERMIT=yellow`) |

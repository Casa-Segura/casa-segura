# CS-169 — BVA tests: B1 down payment ladder + asymmetric clamp

## Context

**B1** scores down payment **percentage vs benchmark**, with explicit asymmetric rule: paying **less** upfront never penalizes vs benchmark ([[RUBRICA_CONTRATO]] §5 B1; [[PRD_GENERAL]] US-03). Tests must cover **both** raw ladder and [[CS-153]] clamp behavior using benchmark **10%** bank/FSV illustrative standard.

## Scope

**In:**
- Table-driven tests on scoring helper with `price_cash` fixed
- Verify scores for above-benchmark staircases (10→15→20→35→>35)
- Pair each above-benchmark case with mirror **below-benchmark** case proving score **does not improve** when increasing deposit beyond benchmark — actually asymmetric: lower down payment should score **≥** benchmark mapping — construct adversarial LLM output feeding clamp

**Out (explicit):**
- Percent extraction accuracy — [[EPIC-04-classification]]

## Acceptance criteria

- [x] Ladder table assuming benchmark standard **10%** (developer direct financing category uses rubric narrative ranges — fixture selects bank segment):

| Down % | Expected score (pre-asymmetric raw ladder) |
|---|---|
| 10.0 | 10 |
| 12.0 | 8 |
| 15.0 | 8 |
| 15.01 | 5 |
| 20.0 | 5 |
| 20.01 | 2 |
| 35.0 | 2 |
| 35.01 | 0 |

- [x] Asymmetric pair: **8%** vs **10%** → mapped scores satisfy `score(8%) ≥ score(10%)`
- [x] Edge at **full price prepaid fraud pattern** (>35% or rubric "full delivery before deed" flag) → **0**

### BVA — boundary value analysis

| Down % | Boundary meaning |
|---|---|
| 9.99 vs 10.00 | favorable vs at benchmark |
| 14.99 vs 15.00 | high tier boundary |
| 34.99 vs 35.00 | very high vs fraud pattern |

## Test intent (Rule 9)

Wrong-sided penalties punish liquidity-constrained buyers — asymmetry tests fail if scoring treats **lower** down payment as strictly worse than benchmark tier ([[RUBRICA_CONTRATO]] §5 B1 narrative).

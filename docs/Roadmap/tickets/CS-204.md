# CS-204 — Render category breakdown with collapsible criterion rows

## Context

Section 4 conveys per-category diligence with six weighted buckets collapsed by default to reduce overwhelm while preserving justification access ([[RUBRICA_CONTRATO]] §11.1 Section 4). Implementation must reconcile visible partial scores with stored `scores_by_category` JSON integrity ([[PRD_F6_GENERACION_REPORTE]] §3 US-05).

## Scope

**In:**
- Six category blocks rendered only when upstream marks category as applicable for the contract type; **omit entirely** unused categories ([[PRD_F6_GENERACION_REPORTE]] §3 US-05 "not shown as score 0")
- Each block exposes category label, declared weight from rubric constants, horizontal progress bar proportional to normalized partial score, collapsed summary row count
- Per-criterion listing with icon/state mapping (green/yellow/red/unverifiable) + short justification; collapsed by default with expand disclosure using inline JS from [[PRD_GENERAL]] BR-13
- Responsive layout: stacked on mobile vs two-column criterion grid desktop per §3 US-05

**Out (explicit):**
- Editing scores post hoc
- Tooltips requiring external libs
- Per-criterion drill linking to corpus (handled in findings/legal sections)

## Acceptance criteria

- [ ] Given JSON `scores_by_category` with `{A,B,C,D,E,F}`, rendered weighted visual bars reproduce numeric values within ±0.05 display tolerance vs raw floats (rounding policy documented once in template helper tests)
- [ ] Given fixture where category **F** irrelevant, DOM contains **no** heading node for category F (snapshot diff fails if placeholder renders "0")
- [ ] Given ≥1 unverifiable criterion, row shows muted ⊘ semantics with plain-language reason string not empty

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| Applicable criterion count per category | 0 vs ≥1 | 0 inside category ⇒ entire category omitted; ≥1 ⇒ render |
| Mobile width | <600 vs ≥960 | Narrow: single-column list; Wide: dual-column criterion grid |

## Test intent (Rule 9)

Omitting irrelevant categories communicates honest scope; rendering a fabricated zero-valued category deceives buyers about diligence coverage relative to weighted math in §11 — DOM absence/presence assertions encode that contract.

## Notes

- Expansion affordances must remain keyboard reachable (baseline a11y: `button` or `details/summary`)

# CS-293 — Loading state with rotating Spanish reassurance copy

## Context

Analysis targets **under 90 seconds at P95** ([[PRD_GENERAL]] §6). During polling, the UI must never feel frozen ([[UI-UX Documents/UI-UX]] §1): rotating status lines keep trust and set expectations while [[CS-296]] polls ingestion/analysis state.

## Scope

**In:**
- Deterministic rotation of 3–5 short Spanish **tú** strings specific to **contract** analysis (not billboard “Flow 1” lines unless optionally reused)
- Visible busy indicator (spinner/progress) + `aria-live="polite"` region for copy changes
- Integrates with submission/poll lifecycle from [[CS-291]]

**Out (explicit):**
- Accurate percent completion (no fake progress bar without BE metric)
- Push/WebSocket streaming — future

## Acceptance criteria

- [ ] Given polling active, when ≥4s elapses, when user watches, then status text has changed at least once (rotation cadence 4–6s configurable constant)
- [ ] Given a screen reader, when copy updates, then the live region announces changes without stealing focus
- [ ] Given completion, when terminal state arrives, then rotation stops and user is routed per channel ([[CS-294]] for `web_link`, or confirmation for async channels)
- [ ] Given failure, when BE returns terminal error, then loading UI exits to error panel with retry affordance where safe
- [ ] Given reduced motion preference (`prefers-reduced-motion`), when enabled, then animation minimizes per platform norm; text still updates

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| Poll interval | fast vs slow | Copy still rotates on wall clock, not only on poll responses |
| Total wait | approaching **90s** | UI shows calmer “sigue en proceso” variant at ≥60s (exact threshold documented in code) |
| Terminal enums | `not_analyzable` vs success | Distinct messaging hook for contract-rejection path |

## Test intent (Rule 9)

Perceived performance is part of accessibility and trust for anxious users. Tests must fail if the live region is missing (SR users hear silence) or if motion can’t be reduced.

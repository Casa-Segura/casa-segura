# CS-087 — Calibrate RAG similarity threshold using eval harness

## Context

Baseline threshold **0.65** is provisional until measured against labeled pairs. The hackathon-era “≥10 pairs” guidance expands to **≥30** curated eval cases spanning **six** rubric categories per [[STATUS_RECONCILIATION]] §Material deltas (#4); epic definition of done mirrors that scale.

## Scope

**In:**

- Build repeatable script consuming [[CS-088]] YAML/JSON fixtures: for each `(finding_text, gold_chunk_anchor/pair)` compute top-1 cosine; aggregate precision/recall & confusion matrix analogue.
- Threshold sweep parameterized (`0.55..0.80` coarse steps plus fine deltas around `.65`).
- Automated regression gate in CI enforcing **minimal precision** negotiated with product — initial placeholder target: Top-1 exact anchor match ≥ **0.85** on fixture set (`pytest -k rag_eval`) until PM revises ([[PRD_F3_CORPUS_Y_RAG]] §9 NFR Top-1 precision).
- Produce human-readable Markdown summary artifact in CI stdout (acceptable) recommending default env `RAG_SIMILARITY_THRESHOLD` — no permanent doc file unless Ops requests.
- Explicitly benchmark boundary triple **0.649 / 0.650 / 0.651** to validate comparator aligns with retrieval module.

**Out:**

- Auto-tuning criterion-specific thresholds (future enhancement referenced in §10).

## Acceptance criteria

- [ ] Harness runs locally <10 minutes CPU on corpus ≤1000 chunks (performance guard optional skip if heavy — mark `@slow`).
- [ ] Sweep output clearly states chosen default threshold rationale referencing precision/recall tradeoff bullets.
- [ ] CI fails if regressions drop metric > agreed delta vs stored baseline artifact (pinned JSON summary committed in-repo under `fixtures/rag-eval-baseline.json` — permissible small data file tracked by ENG lead).
- [ ] Harness logs **never** persist raw findings—only hashed IDs aligning with telemetry ticket.

### BVA — boundary value analysis

| Similarity | Threshold | Decision |
|---|---|---|
| 0.649 vs 0.650 vs 0.651 vs `t=0.65` | strict GE | Mirrors production comparator; mismatches cause harness false positives |

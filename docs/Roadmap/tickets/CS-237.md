# CS-237 — Wire email delivery worker path end-to-end

## Context

Queue consumer must orchestrate decryption (where needed), PDF generation invocation, MIME build, SMTP send, and ciphertext purge via shared dispatcher semantics ([[CS-231]], [[CS-232]], [[CS-235]], [[CS-236]]).

## Scope

**In:**
- Task handler retrieving `DeliveryRequest` row, validating channel=`email_pdf`
- Calls F6 PDF generator port (provided by [[CS-209]])
- Sends via SMTP client, translates failures through CS-243 classification hook
- On success transitions `delivery_status` on parent `ContractAnalysis` to `sent_email` (per PRD §5.3 values) respecting ENUM alignment backlog
- Emits Prometheus counters `delivery_attempt_total{channel=email,...}` scaffolding

**Out (explicit):**
- PDF/HTML failure fallback messaging (explicitly flagged open question §10 Q1 — document outcome in orchestrator Notes)

# CS-025 — Schema: ContractSubmission + OcrJob (transient, expires_at)

## Context

Ingestion uses transient rows for idempotency and OCR observability ([[DOMAIN_MODEL]] §4.1–4.2; [[FEATURES_MAP]] §4 F1). Migrations must enforce **no persisted contract text**, 24h TTL defaults, and cascading cleanup hooks for `ocr_job` rows.

## Scope

**In:**
- `contract_submission` table per PRD DDL: `processing_status` enum, file metadata, `public_short_id`, disclaimer acceptance timestamps, `expires_at` default `now()+24h`
- `ocr_job` table with FK `submission_id` `ON DELETE CASCADE`, strategy enum (`pypdf|vision_llm|tesseract`), attempt metadata, `expires_at` default `now()+24h`
- Indexes: submission hash, status, expires_at, analysis linkage; ocr_job submission/status/expires
- ORM models + relationship helpers (submission.jobs)

**Out (explicit):**
- Cleanup cron — [[EPIC-09-retention-privacy]]
- OCR execution logic — [[EPIC-02-ingestion-ocr]]

## Acceptance criteria

- [x] Given parent submission deleted, when CASCADE configured, when child `ocr_job` rows existed, then they are removed automatically
- [x] Given insert without overriding `expires_at`, when default applies, then TTL is ~24h forward within one minute skew tolerance
- [x] Given `processing_status='completed'` row, when cleanup policy from PRD is cited, then schema supports nullable `analysis_id` FK to `contract_analysis`
- [x] Given DOMAIN constraint “no extracted text persisted”, when inspecting columns, then only `extracted_text_token_count` / language fields exist—no `extracted_text` column can be added without new ticket + privacy review
- [x] Given OCR enum strategies, when illegal strategy string inserted, then CHECK constraint fails

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| `expires_at` vs `NOW()` | cleanup threshold | Rows with `expires_at < now()` eligible for deletion job; document test clock injection |
| `file_count` | 1 vs 50 vs 51 | PRD DDL CHECK allows 1–50; 51 rejected |
| Job `status` | terminal states | `success|failed|timeout|cancelled` per PRD DDL align to DOMAIN `running|success|failed|timeout`—use PRD DDL as source |

## Test intent (Rule 9)

Transient tables are the privacy perimeter’s pressure valve; if TTL defaults or cascades break, OCR retries leak rows forever. Tests must prove cascade + expiry defaults and absence of text columns.

## Notes

- Align `vision_llm` naming with [[DOMAIN_MODEL]] `VISION_LLM` enum semantics (case mapping at API boundary).
- `disclaimer_accepted_at` NOT NULL enforces BR-07 gating at persistence layer.

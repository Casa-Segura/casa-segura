# CS-006 — Secrets baseline (.env.example with full env surface)

## Context

Operators and developers need one authoritative list of configuration keys. [[BE-SERVICES]] §9 enumerates integration and ML/RAG/OCR variables; persistence and retention jobs add database and job tuning keys in [[PRD_F8_PERSISTENCIA_PROYECTO_RETENCION]] §6.3. The committed template is the mechanical backbone for BR-07 copy (the FR **lives in code**, but env docs prevent accidental misconfiguration).

## Scope

**In:**

- **`backend/.env.example`** (canonical; consumed by `django-environ.Env.read_env(BASE_DIR / ".env")`) listing every surfaced key with short operator comments + placeholders
- Grouping headers covering Django core, Postgres/Redis/Celery, OpenRouter, OCR/RAG, SMS/KMS, retention jobs, optional EPIC-12 flags, Railway notes
- Explicit never-commit-secrets guidance referencing `README` onboarding

**Out (explicit):**

- Parsing code beyond what already exists in `config/settings.py`
- Production secret provisioning — operations

## Acceptance criteria

- [x] Given **`backend/.env.example`**, reviewers can map every **BE-SERVICES §9** “Existing / New” key to a documented entry (`DATABASE_URL` vs discrete `DB_*` is explained inline + in `config/settings.py`)
- [x] OCR/RAG keys (`OCR_FALLBACK_ENABLED`, `TESSERACT_LANG`, `PDF_MAX_PAGES`, `EMBEDDING_*`, `RAG_TOP_K`, `RAG_SIMILARITY_THRESHOLD`, etc.) are enumerated with BVA comments (0.649 / 0.651 story, reject-on-exceed for `PDF_MAX_PAGES`, etc.)
- [x] PRD F8 keys (`DB_POOL_*`, `ANONYMIZATION_AFTER_DAYS`, `JOB_BATCH_SIZE`, `JOB_TIMEZONE`, …) are present alongside the operational Postgres/Celery knobs
- [x] **`REPORT_LINK_TTL_DAYS`** documents the EPIC-07 proposal (30 day default) without implying it is already enforced everywhere
- [x] Fresh clone smoke: copy **`backend/.env.example` → `backend/.env`**, start Dockerized Postgres/Redis, run **`poetry run python manage.py check`** → **0 errors** (**verified 2026-05-17**). `SECRET_KEY` now ships a documented *local-only* literal; **never** ship that value to shared environments. **`OCR_MAX_BYTES` must not use inline `#` comments on the same line** (breaks `django-environ` casting).

### BVA — boundary value analysis

| Input | Boundary | Expected documentation in `.env.example` |
| --- | --- | --- |
| `ANONYMIZATION_AFTER_DAYS` | product min/max | Comment states default 90; downward-only adjustment allowed per PRD BR-03; lengthening requires privacy review |
| `RAG_SIMILARITY_THRESHOLD` | 0.65 nominal | Comment cites 0.649 vs 0.651 behavior (“cite or stay silent”) per [[STATUS_RECONCILIATION]] |
| `PDF_MAX_PAGES` | upper reject | Comment states contracts beyond limit are rejected (`not_analyzable` / ingestion error) |

## Test intent (Rule 9)

Drift between documented env vars and runtime reads is an outage vector. If code reads something missing from **`backend/.env.example`**, or the template lists ghosts, the ticket reopens.

## Notes

- Operators on Railway inherit `DATABASE_URL`; `.env.example` stays focused on Compose-friendly `DB_*` defaults with a documented override narrative.
- Optional integrations (`OPENROUTER_API_KEY`, SMS fields, KMS) intentionally keep angle-bracket placeholders.

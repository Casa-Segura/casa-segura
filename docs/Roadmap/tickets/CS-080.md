# CS-080 — Build corpus loaders for markdown law sources

## Context

Legal RAG anchors on curated Salvadoran statutes packaged as Markdown in `Projects/Casa Segura/RAG Legal context/laws/` (seven entries per [[RAG Legal context/README]], including stub `06`). [[PRD_F3_CORPUS_Y_RAG]] BR-10 designates markdown as **source of truth** ahead of DB projections.

## Scope

**In:**

- Loader module scanning the seven Markdown sources with YAML frontmatter per [[DOMAIN_MODEL]] §3.5 / [[PRD_F3_CORPUS_Y_RAG]] §US-01 exemplar (`law_id`, `title`, `decree`, `last_verified`, etc.).
- Map file paths deterministically (`01-ley-inquilinato.md`, … `07-ley-urbanismo-construccion.md`, plus stub handling — flag `status=stub` rows must **skip embedding** ingest or ingest with explicit `active=false` policy decided in ingestion orchestrator documented in Notes).
- Compute per-law `content_hash` for drift detection versus prior ingest.
- Transform parsed metadata into staged `LegalDocument` ORM payloads keyed by `(law_id, corpus_version)` placeholders prior to transactional insert ([[CS-084]] consumes).
- Unit tests fixing minimal fixtures referencing snapshot headers.

**Out (automatic):**

- Fetching authoritative HTML/PDF conversions from ministerial portals (manual curator workflow unchanged).

## Acceptance criteria

- [ ] Given the current repo tree, loader enumerates exactly **seven** filenames from [[RAG Legal context/README]] canonical list OR fails loudly if filenames drift (prevent silent partial ingest).
- [ ] Given malformed frontmatter, loader raises structured `ParseError` with law file path reference (no corpus text dump in traceback logs).
- [ ] Given duplicated `law_id` across files, ingestion preflight rejects before DB transaction.
- [ ] Stub file `06` produces warnings in report JSON but does not abort entire batch **unless strict mode enabled** (`--fail-on-stub`), default behavior documented alongside [[CS-084]] CLI.

### BVA — boundary value analysis

| Scenario | Boundary | Expected |
|---|---|---|
| Stub law presence | Stub vs absent | Operational policy triggers warning vs fatal via flag |
| Content hash drift | unchanged vs whitespace-only change | Hash stable rules documented (normalize newlines)

## Test intent (Rule 9)

Loader tests ensure **canonical law inventory** parity with curated README — corpus drift or missing mandates should halt automated publish, preventing silent omission of foundational articles.

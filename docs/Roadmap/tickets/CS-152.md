# CS-152 — Implement weighted score aggregation per §10

## Context

Category scores are weighted averages of applicable criteria; global score combines categories with global weights A–F, renormalizing when categories are absent ([[RUBRICA_CONTRATO]] §10). This ticket implements the **pure numeric core** assuming each criterion row already carries final `score`, `weight_in_category`, `category`, and `applicable_types` membership for the active contract type.

## Scope

**In:**
- Pure function `compute_category_scores(contract_type, evaluations)` implementing §10 steps filtering `contract_type ∈ applicable_types` and per-category weight renormalization: \(\sum w_i s_i / \sum w_i\)
- Global combination with weights **A=0.20, B=0.30, C=0.20, D=0.15, E=0.10, F=0.05**, omitting categories with zero applicable criteria and renormalizing global weights over remaining categories
- `round(score_total, 1)` per §10 snippet
- Structured output matching [[PRD_F4_MOTOR_RUBRICA]] §5.4 `scores_by_category` fields (`criteria_count_*`, `weight_global`, `weight_effective`)

**Out (explicit):**
- Override early-return forcing zero — [[CS-157]]
- Band labeling — [[CS-156]]
- LLM calls / evaluators — [[CS-158]]

## Acceptance criteria

- [ ] Given a synthetic CVP analysis where category B has seven applicable criteria with known weights and scores, returned `score_category["B"]` equals hand-calculated weighted average within floating tolerance **ε ≤ 1e-9**
- [ ] Given a contract type where category F has **no** applicable criteria, global weights over A–E renormalize to sum **1.0** and F does not appear in `scores_by_category`
- [ ] Given all six categories present, effective global weights equal nominal weights (sum 1.0) without rescaling
- [ ] Given duplicate criterion ids in input, aggregation rejects or dedupes with explicit error — no silent double-count
- [ ] Given `score_total` intermediate value `7.949999`, rounded persisted scalar is **7.9** (banker's rounding policy documented if differing)

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| Single applicable category | only A present | `score_total == score_A`; effective weight A = 1.0 |
| Empty applicable set | zero criteria all categories | explicit error `NO_APPLICABLE_CRITERIA` |
| Category internal weights | one criterion weight 100% of cat | equals that criterion score |
| Global renormalization | drop F (5%) | remaining weights scaled so sum=1 |
| Rounding | 7.95 vs 7.94 before round(,1) | documented deterministic mapping |

## Test intent (Rule 9)

A regression that changes renormalization arithmetic must shift **reported user score** for mixed-applicability types (e.g. CVC vs CVP); tests compare against **closed-form fixtures** from [[RUBRICA_CONTRATO]] §10, not implementation internals.

# CS-115 — Build classification evaluation set (≥20 contracts)

## Context

[[PRD_F2_CLASIFICACION]] §9 mandates classification quality metrics (≥95% success on in-scope docs; reclassification FP/FN budgets). This ticket curates **≥20** de-identified contract fixtures spanning all eight rubric-applicable types plus `NOT_CLASSIFIABLE` negatives, covering leasing edge cases and confidence-band behavior so regressions surface before production.

## Scope

**In:**
- Fixture corpus stored version-controlled (no PII; synthetic + licensed samples).
- Expected labels: gold `contract_type`, optional gold leasing indicators for CVP/APV/CVC scenarios.
- Automated harness invoking orchestration behind `POST /v1/internal/classify` ([[PRD_F2_CLASIFICACION]] §7.1) or equivalent service-level API.
- Metrics script reporting accuracy by type, `NOT_CLASSIFIABLE` precision, reclassification confusion subset.

**Out (explicit):**
- Prompt authoring ([[CS-110]]) — consumes outputs only.
- Corpus/RAG eval ([[EPIC-03-corpus-rag]]).

## Acceptance criteria

- [ ] Corpus contains **at least three** fixtures per covered purchase/lease family (`CVC`, `CVP`, `ARV`, `ARC`, `APV`, `LEA`, `IVU`, `FSV`) and **≥4** explicit `NOT_CLASSIFIABLE` negatives drawn from PRD exclusions ([[PRD_F2_CLASIFICACION]] US-06 list).
- [ ] Total fixture count ≥ **20** unique scenarios documented in index Markdown with IDs linking to JSON expectation files.
- [ ] Harness asserts final stored `contract_type` AND post-[[CS-111]] reclassification outcomes match gold labels within allowed tolerance documented per scenario (deterministic mismatches filed as bugs).
- [ ] CI job (or documented manual gate) fails when macro accuracy drops below configurable thresholds aligned with §9 targets — thresholds declared in README snippet beside corpus.

### BVA — boundary value analysis

| Scenario class | Boundary | Expected |
|---|---|---|
| Leasing indicators | Exactly 3 vs 4 true | Label expects purchase vs `LEA` post [[CS-111]] |
| Confidence harness | Fixture forcing 0.66 confidence | Expect validation branch exercised (`classification_attempts = 2`) |

## Test intent (Rule 9)

Dataset membership encodes **rubric enum completeness** — missing `ARC` or `IVU` fixtures must fail coverage gates because applicability matrices assume coverage ([[RUBRICA_CONTRATO]] §3).

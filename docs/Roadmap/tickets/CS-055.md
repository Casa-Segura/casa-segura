# CS-055 — Add Tesseract Spanish OCR fallback path

## Context

When OpenRouter vision is throttled or fails en masse, **local Tesseract** (`spa`) is the free fallback ([[BE-SERVICES]] §3.3, `OCR_FALLBACK_ENABLED`, `TESSERACT_LANG=spa`). [[PRD_F1_INGESTA_Y_OCR]] §US-07 defines activation rules, per-page **30s** timeout, and **minimum confidence 60** from `image_to_data`.

## Scope

**In:**

- Wire `pytesseract` + system Tesseract with Spanish traineddata.
- PDFs: reuse `pdf2image` path with configured DPI; images: optional light preprocessing (grayscale, Otsu) per PRD.
- Gate activation:
  - (a) vision failure / partial threshold path from [[CS-054]], and/or (b) `OCR_COST_SAVER_MODE=true` forcing Tesseract first for images (**product default false**).
- Honor **30s**/page timeouts; aggregate page text with same separators as other strategies for downstream consistency.
- Compute **average confidence** across pages; if **< 60**, mark OCR job failed (submission follows [[CS-056]] outcomes).
- Environment alignment: prefer names from PRD (`OCR_TESSERACT_*`) mapping to deployment (`OCR_FALLBACK_ENABLED`, `TESSERACT_LANG` from [[BE-SERVICES]] §9) documented in README for ops — no user-facing Markdown files unless ops ticket requests.

**Out (explicit):**

- Training custom OCR models or shipping `spa.traineddata` in repo licensing review (must document install path).

## Acceptance criteria

- [ ] Given `OCR_TESSERACT_ENABLED=false`, when fallback would trigger, then system **does not** invoke `pytesseract` and surfaces vision-only failure messaging.
- [ ] Given simulated vision outage and enabled fallback, when fallback runs on a deterministic synthetic image fixture, then `OcrJob.strategy=tesseract`, `tokens_consumed` null/0, `cost_estimate_cents` 0 ([[DOMAIN_MODEL]] §4.2).
- [ ] Given pytesseract reports per-word confidences yielding **average 59.9**, when averaged, then job **fails**; at **60.0** passes (see BVA).
- [ ] Logs contain **no** full OCR text at INFO/DEBUG defaults; truncated preview ≤ 256 chars or hash-only.

### BVA — boundary value analysis

| Metric | Boundary | Expected |
|---|---|---|
| Mean OCR confidence | 59.9 / 60.0 / 60.1 | Strict PRD comparator: `<60` fails; `≥60` success |
| Per-page timeout | 30s | Exceed → page failure |
| Activation | vision partial failure vs cost_saver_mode | Ensures mutually exclusive precedence tested |

## Test intent (Rule 9)

The **confidence threshold** prevents shipping gibberish “success” OCR that fails Salvadoran renters downstream — tests must anchor to PRD numeric cutoff, not “non-empty string” checks.

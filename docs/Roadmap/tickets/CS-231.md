# CS-231 — Implement channel-agnostic delivery dispatcher

## Context

Queues and HTTP handlers enqueue `DeliveryRequest` work without duplicating channel semantics ([[EPIC-08-multichannel-delivery]] goal). Dispatcher routes to pluggable channel handlers while preserving uniform state transitions (`queued → sending → terminal`).

## Scope

**In:**
- Service interface `enqueue_delivery(analysis_id, channel, …)` returning request id
- Priority + `not_before` scheduling hooks consumed by worker ([[CS-233]])
- Hooks to call F6 (`generate_report_pdf`, `generate_report_html`) through narrow ports defined in [[CS-247]] / channel tickets
- Centralized transition guards preventing illegal jumps (e.g., `delivered → sending` without new `DeliveryRequest`)

**Out (explicit):**
- Provider-specific error translation (lives in [[CS-243]])
- Public HTTP routes (CS-245/248)

## Acceptance criteria

- [x] Given mocked channel handler success, dispatcher records `status` sequence observable in test fake: `queued` pre-worker, `sending` during handler, `delivered` after handler ack
- [x] Given handler raises classified `permanent` error, dispatcher sets terminal `failed` without scheduling additional attempts (bypassing CS-234)
- [x] Given concurrent enqueue attempts for same analysis same channel violating product rule "single simultaneous destination pipeline", deterministic conflict policy triggers (reject or idempotent reuse) documented in README fragment

### BVA — boundary value analysis

| State transition | Boundary | Expected |
|---|---|---|
| From `failed` | re-enqueue vs blocked | Requires fresh `DeliveryRequest` row flagged `is_resend` per PRD semantics |
| `web_link` | immediate availability path | Dispatcher may finalize without SMTP/SMS handlers while still stamping contract-level `delivery_status` |

## Test intent (Rule 9)

If dispatcher bypasses the `sending` state machine, SLA metrics ([[PRD_F7_ENTREGA_MULTICANAL]] §9) falsely show instant delivery while attachments never actually leave the system — assert intermediate state visibility.

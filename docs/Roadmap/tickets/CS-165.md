# CS-165 — Verdict synthesis prompt and service

## Context

The executive summary (2–3 sentences, Spanish **tú**) orients non-lawyers before they read findings ([[PRD_F4_MOTOR_RUBRICA]] US-08). It must **not** introduce legal citations or numeric figures reserved for other sections ([[PRD_GENERAL]] BR-02 alignment).

## Scope

**In:**
- Final LLM call consuming: `score_total`, `band`, override codes + Spanish titles from [[CS-151]], severity counts, contract type text, **sanitized** economic headline strings allowed by prompt policy (PRD §8.3 forbids exact figures — enforce minimal/no numeric leakage)
- Persist `executive_summary` on `ContractAnalysis` ([[PRD_F4_MOTOR_RUBRICA]] §5.3)
- Temperature defaults per BR-07 discussion (document chosen value)

**Out (explicit):**
- SMS/email delivery composition — [[EPIC-08-multichannel-delivery]]
- Full findings prose rewriting — already per criterion

## Acceptance criteria

- [ ] Given green-band fixture without overrides, summary explicitly acknowledges favorable posture and still advises lawyer consult ([[PRD_F4_MOTOR_RUBRICA]] §8.3 examples)
- [ ] Given active override list non-empty, summary names problem severity without quoting statute text **verbatim** (pattern-based assertion via forbidden substring list `Art.`, `Código`, `Ley`)
- [ ] Given summary longer than **4** sentences or **450** characters, validator rejects and triggers single repair pass with constrained prompt
- [ ] Given identical inputs twice with pinned model config, outputs match within acceptable variance policy documented for MVP reproducibility ([[PRD_F4_MOTOR_RUBRICA]] §9)
- [ ] Given pipeline failure after repair pass, persist deterministic fallback string tagged `executive_summary_fallback=true`

### BVA — boundary value analysis

| Input | Boundary | Expected behavior |
|---|---|---|
| Override present vs absent | boolean | tone shift required |
| Critical count | 0 vs ≥1 | urgency wording |
| Band | yellow vs red | escalation lexicon allowed |
| Summary length | 3 vs 4 sentences | hard reject >3 after repair |

## Test intent (Rule 9)

Prompt regressions that re-introduce **verbatim legal citations** into the headline violate BR-02 / PRD §8.3 — substring guards must fail CI ([[CS-166]] overlaps).

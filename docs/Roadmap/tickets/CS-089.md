# CS-089 — Persist hashed RAG telemetry for citation auditing

## Context

Citation quality requires correlating retrieval decisions with eventual findings without leaking PII ([[PRD_F3_CORPUS_Y_RAG]] telemetry list + RagQueryLog model). Rows age out at **TTL = 90 days** while transient OCR entities expire at **24h** — tests must anchor retention separately.

## Scope

**In:**

- Create / migrate `rag_query_log` per PRD schema (uuid id, hashed query text `query_text_hash`, analysis_id FK optional nullable pre-F4 threading, criterion_id nullable, corpus_version, `top_k`, threshold numeric(3,2), optional filter arrays snapshot, counts, top_score numeric, timestamps, `expires_at = now()+90days`).
- Django model + nightly/periodic pruning job aligning with FEATURES_MAP privacy cadence distinctions (coordinate EPIC-09 if centralizes TTL sweeps — until then Celery beat docstring acceptable).
- Hook retrieval service to INSERT after each query (transactions batched minimally to avoid hotspots).
- Ensure logs never store raw finding text strings (hash only, e.g., SHA-256 of normalized phrase).
- Grafana-friendly counters exported: empty-result rate histogram.

**Out:**

- User-facing dashboards.

## Acceptance criteria

- [ ] Integration test asserting row inserted post-query with deterministic hash for fixed input string.
- [ ] TTL pruning test using time-freeze: simulate `expires_at` past boundary ensures DELETE job removes row (`rag_query_log` count 0).
- [ ] Unauthorized DB role cannot SELECT sensitive columns beyond operational needs — optional(RLS backlog) flagged if required by SecOps (note only).
- [ ] Verified diff vs OCR tables: TTL constant **90d ≠ 24h** documented in migration comments to prevent accidental reuse of generic cleanup runner without parameterization.

### BVA — boundary value analysis

| Policy | Boundary | Expected |
|---|---|---|
| TTL | NOW vs NOW−89d vs NOW−90d1s | Row present vs purge eligibility |
| top_k persisted | aligns with retrieval param | rejects negative values |

## Test intent (Rule 9)

Enforces telemetry **without content leakage** and distinguishes **retention horizons** versus OCR logging — simplifying TTL reuse would violate privacy partitioning ([[DOMAIN_MODEL]]).

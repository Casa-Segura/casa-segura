- Environment variables configured for [[CS-296]] (server-only secrets)

**Out (explicit):**

## Acceptance criteria

- [ ] Given push to `main`, when CI completes, when Vercel builds, then deploy succeeds with green build logs
- [ ] Given production URL, when curling `/`, when checked, then returns `200` and renders [[CS-290]]
- [x] Given missing env `CASASEGURA_API_BASE_URL`, when build-time or runtime check executes, then deploy fails loudly in preview with checklist message
- [x] Given `robots.txt` policy, when reviewed, then staging/preview disallow crawlers if exposing WIP (product decision documented)

## Test intent (Rule 9)

Misconfigured deploys leak **secrets to the browser** or ship broken env splits. Tests must fail if `NEXT_PUBLIC_` is used for privileged API keys or if production points at dev backend unintentionally.

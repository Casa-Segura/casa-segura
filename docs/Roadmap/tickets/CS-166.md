# CS-166 — Synthesis output validator (no ungrounded citations)

## Context

Downstream narrative layers must never fabricate law citations ([[PRD_GENERAL]] BR-02). F3 supplies `legal_basis`; synthesis may only restate facts grounded in allowed inputs ([[PRD_F4_MOTOR_RUBRICA]] BR-05, US-03).

## Scope

**In:**
- Deterministic post-processor scanning `executive_summary` + optional LLM-generated connector fields for **article markers** (`Art.`, ordinal patterns, known law abbreviations corpus)
- Allow-list approach: if matcher fires, ensure referenced anchor appears in retrieved chunk id list attached to analysis snapshot **or** strip/repair via single rewrite prompt
- Metrics hook: count violations blocked vs repaired

**Out (explicit):**
- Full report HTML validator — [[EPIC-07-report-generation]]

## Acceptance criteria

- [ ] Given summary containing substring `Art. 12` absent from allowed retrieval id allow-list, gate raises `UNGROUNDED_CITATION` and triggers rewrite or replaces with generic warning sentence
- [ ] Given summary without legal tokens, validator passes without mutation
- [ ] Given allowed paraphrase referencing law **by generic phrase** ("la ley de consumidor") without article enumeration, passes — document regex scope to avoid false positives
- [ ] Given validator rewrite failure, summary downgrades to template A/B/C based on band only (no statutory text)
- [ ] Golden files cover Override-red path ensuring **no** statute numbers leak through repair

### BVA — boundary value analysis

| Token | Boundary | Expected |
|---|---|---|
| `Art.` | uppercase vs lowercase unicode | both caught |
| Article number | `Art. 12` vs `Artículo 12` | both caught |
| Allowed list | cited chunk removed retroactively | fails closed |
| Empty allow-list | retrieval outage | template fallback |

## Test intent (Rule 9)

Validator encodes **legal risk containment** — silently publishing citations not traceable to curated corpus breaks product promise ([[FEATURES_MAP]] F3 purpose).

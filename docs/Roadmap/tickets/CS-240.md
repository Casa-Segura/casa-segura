# CS-240 — Compose SMS summary (Spanish, "tú")

## Context

Template-driven SMS copy must distill the score/band, full-report URL, expiration, analysis ID, and disclaimer without exceeding the configured SMS segment budget ([[PRD_F7_ENTREGA_MULTICANAL]] §3 US-03, [[RUBRICA_CONTRATO]] §13.2 pattern).

## Scope

**In:**
- Input shaping from `ContractAnalysis` + delivery/link metadata
- SMS body links to the full report rather than attempting to include legal citation lines inline
- Enforce configured SMS segment budget before enqueue
- Register variables consumed by [[CS-239]] validator

**Out (explicit):**
- LLM generation (static template fields only)
- Inbound conversational resend handling is out of MVP

## Acceptance criteria

- [x] Golden tests for Spanish diacritics ensure NFC normalization before counting length
- [x] Composer always includes link, ID, and disclaimer shorthand when input data is complete
- [x] Output record logs only statistical digest (length, bullet count) — no PII ([[PRD_F7_ENTREGA_MULTICANAL]] §4 BR-15)

### BVA — boundary value analysis

| Message body | Boundary | Expected |
|---|---|---|
| Segment budget | budget vs budget+1 | Budget+1 blocks send and falls back to web-link/email delivery copy |

## Test intent (Rule 9)

Exceeding SMS limits can silently truncate the disclaimer or link — budget tests fail if composer cannot guarantee required fields remain intact.

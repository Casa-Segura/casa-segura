# CS-350 — Billboard OCR extraction via vision LLM (structured JSON)

## Context

Optional **project verification** reuses the hackathon-era Flow 1 framing from [[ARCHITECTURE]] §5 as a **standalone** path: photograph billboard → structured fields (**developer, project name, permit, address**) separate from contract analysis ([[STATUS_RECONCILIATION]], [[EPIC-12]]). OCR must mirror [[BE-SERVICES]] billboard routing without persisting imagery.

## Scope

**In:**
- Vision OpenRouter prompt + JSON schema validating required keys (nullable where unknown)
- Service function `extract_billboard(bytes, content_type) -> structured record` with timeouts and deterministic error enums
- **No `session_id` gate** tying later contract upload ([[STATUS_RECONCILIATION]])
- Telemetry hooks compatible with anonymized latency metrics ([[CS-330]]) — emit stage timing only

**Out (explicit):**
- Curated blacklist / developer reputation corpus (explicitly forbidden in MVP interpretation of [[PRD_GENERAL]] BR-11 for blacklist; EPIC‑12 treats reputation as optional pluggable lookup only in [[CS-353]])
- Storing billboard images to disk/object storage (“no persistent billboard storage”[[EPIC-12]] )
- Blocking contract ingestion when OCR fails (**non‑blocking** mandate)

## Acceptance criteria

- [ ] Given a valid billboard image fixture in staging, extractor returns populated fields or explicit `low_confidence` without raw transcript returned to frontend logs (transcript handled per [[CS-331]])
- [ ] Given malformed input (non-image MIME), endpoint returns typed `UNSUPPORTED_MEDIA` schema
- [ ] Structured output validates against pydantic/dataclass; rejecting model hallucinations beyond max string lengths
- [ ] OCR failure transitions route to documented enum consumed by [[CS-351]] without requiring user reload
- [ ] Successful path emits **latency metric** labeled `flow=project_verification` stage `billboard_vision` ([[PRD_GENERAL]] §5 anonymity rules)

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| Vision timeout | T-1 ms vs T+1 ms deadline | categorized as structured `timeout`, not ambiguous 500 spam |
| Image pixel count | min supported vs oversize megapixel | rejects early with actionable message |
| `PROJECT_VERIFICATION_ENABLED` | false | route returns HTTP 404/410 per [[CS-356]] |

## Test intent (Rule 9)

Guarantees the optional billboard path preserves **privacy** while still delivering structured semantics for downstream checks—the contract analysis pipeline must operate unchanged when this extraction regresses.

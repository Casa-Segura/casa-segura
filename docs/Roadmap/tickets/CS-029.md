# CS-029 — Schema: DeliveryRequest

## Context

Delivery attempts temporarily hold hashed targets and encrypted destinations ([[DOMAIN_MODEL]] §4.3; [[PRD_GENERAL]] US-05). Schema must encode channel enums, retry counters, `expires_at` default **7 days**, and parent resend linkage—without persisting cleartext email/phone.

## Scope

**In:**
- `delivery_request` table per PRD DDL: channels lowercase `email_pdf|whatsapp_summary|web_link`, status `queued|sending|delivered|failed|expired`
- FK `analysis_id` → `contract_analysis` ON DELETE CASCADE (per PRD DDL)
- Encrypted target columns + optional `target_hash` behavior per PRD (nullable where web_link lacks target)
- Indexes: analysis, status, next attempt timing partial index, expires_at
- ORM relationships from analysis → deliveries

**Out (explicit):**
- Provider integrations (SMTP/Zavu) — [[EPIC-08-multichannel-delivery]]
- KMS wiring — operations + F7 ticket; schema holds columns only

## Acceptance criteria

- [x] Given valid `analysis_id`, when inserting delivery row, when default `expires_at` applies, then TTL ~7 days ±1 minute
- [x] Given `max_attempts` default 3, when row inserted without override, then DB stores 3
- [x] Given illegal `channel` string, when CHECK fires, then reject
- [x] Given `ON DELETE CASCADE` from analysis, when analysis removed in test, then delivery rows drop (confirm expected behavior for GDPR-style purges vs soft-delete policy—document product stance)
- [x] Given columns exist, when inspecting schema, then **no** plaintext email/phone column exists

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| `expires_at` vs cleanup | `< now()` | Row eligible for encrypted purge per PRD US-05/US-08; schema supports NULLing `target_value_encrypted` |
| Retry backoff fields | `next_attempt_not_before` | Nullable until scheduler uses it |
| `attempt_count` vs `max_attempts` | equality | Terminal `failed` state enforced in service layer; DB allows storage |

## Test intent (Rule 9)

A plaintext destination column would violate the privacy contract immediately. Tests must enforce column absence and encrypted-field lifecycle hooks at ORM level (optional serializer guard).

## Notes

- `last_error_classification` CHECK `transient|permanent` per PRD DDL supports Rule 9-ish retry semantics downstream.
- Coordinate deletion semantics with legal retention (7d transient) vs analysis 90d anonymization.

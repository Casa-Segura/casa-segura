# CS-205 — Render highlighted findings with collapsible legal cards

## Context

Detailed findings dominate user comprehension ([[RUBRICA_CONTRATO]] §11.1 Section 5 and §11.2 exemplar). Each finding merges severity, excerpted clause text, actionable recommendation, and optional `LegalReference` payload shaped per [[BE-SERVICES]] §5 (collapse card). BR-07 demands an additional disclaimer pass before exposing critical-ranked material ([[PRD_F6_GENERACION_REPORTE]] §4 BR-02).

## Scope

**In:**
- Deterministic severity ordering (`critical → red → yellow → green/unverifiable` tie-break via criterion weight descending per §3 US-06 intent)
- If any `severity=critical`: insert disclaimer preamble *before* enumerated critical bullets (matching BR-02 "before critical findings")
- Rendering fields: severity marker, title, explanation, monospace-styled cited clause chunk when evidence string present
- Legal reference card: cite line `"{document_title}, {article_number}"`, short paraphrase (`excerpt` field), expandable region revealing longer `text_verbatim` when present (inline only; fetched at render-time from corpus row if hydration required but **never** CDN)
- Conditional footnotes when tags `market_based` / `unverifiable_legal` appear per §3 US-06
- Collapse strategy when total findings **`> REPORT_MAX_FINDINGS_BEFORE_COLLAPSE` default 25**: auto-collapse yellow/green buckets into aggregate **"Otros puntos de observación"** disclosure per §3 US-06 (boundary inclusive/exclusive enumerated in BVA)

**Out (explicit):**
- Full contract text retrieval from storage ([[PRD_GENERAL]] BR-01)
- Remote font/icon packs
- Persisting hydrated HTML snapshots

## Acceptance criteria

- [ ] Given fixture with `{critical ≥1}`, disclaimers appearing before first critical card include verbatim BR-07 root text or registry-managed equivalent
- [ ] Given `legal_reference.similarity` floats, similarity never surfaces to user UI (hidden debug only) per privacy/UX stance but document_title/article_number/excerpt visible
- [ ] Given `text_verbatim` missing, expandable control suppressed or gracefully degrades label "texto íntegro no disponible"
- [ ] Finding count = 26 with default threshold =25 ⇒ yellow/green entries nested inside collapsed aggregator while critical/red remain inlined

### BVA — boundary value analysis

| Metric | Boundary | Expected |
|---|---|---|
| Total findings vs threshold | ≤25 vs 26 | ≤25 all expanded per policy; ≥26 aggregator collapses yellow/green defaults |
| `REPORT_MAX_FINDINGS_BEFORE_COLLAPSE` | 24→25 toggle | Boundary uses **strict greater-than** (>25 collapses); exactly 25 ⇒ no aggregator |
| Critical presence | zero vs nonzero | nonzero triggers extra disclaimer prelude |

## Test intent (Rule 9)

Threshold handling changes user exposure to nuanced yellow findings at scale; asserting only sort order ignores whether low-signal noise is surfaced responsibly versus collapsed per §11 guidance.

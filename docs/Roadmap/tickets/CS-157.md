# CS-157 — Apply critical overrides: force score zero and red band

## Context

Any triggered override invalidates the benign-looking average — final presentation must show **`score_total = 0.0`** and **`band = red`** despite category math ([[RUBRICA_CONTRATO]] §2.2; §10 pseudo-code). Multiple simultaneous overrides accumulate codes in `override_triggered` ([[DOMAIN_MODEL]] §3.2).

## Scope

**In:**
- Orchestrator step merging evaluator outputs: if **any** `override_triggered` non-null among evaluations OR centralized detectors fire, produce final payload `{score_total: 0.0, band: "red", override_active: true}` preserving diagnostic category breakdown optionally for transparency ([[RUBRICA_CONTRATO]] §10 return shape)
- Populate `ContractAnalysis.override_triggered` with stable ordering (alphabetical by code) for deterministic snapshots
- Ensure criterion-level scores for triggering criteria reflect rubric (typically **0** when override active)

**Out (explicit):**
- Rendering CRITICAL banner — [[EPIC-07-report-generation]]
- Detectors embedded in each evaluator — [[CS-159]]–[[CS-164]]

## Acceptance criteria

- [ ] Given one evaluation row with `override_triggered="art_12_lpc"`, final `score_total` is **0.0** regardless of category averages ≥8 ([[PRD_GENERAL]] US-03)
- [ ] Given two overrides from distinct criteria, `override_triggered` length is **2** without duplicates
- [ ] Given no overrides, orchestrator defers to [[CS-152]] + [[CS-156]] outputs unchanged
- [ ] Given override flow, `band` is **`red`** even if rounded aggregate without overrides would be green
- [ ] Golden JSON fixture committed demonstrating override precedence documented in README snippet from §10

### BVA — boundary value analysis

| Condition | Boundary | Expected |
|---|---|---|
| Override flag present vs absent | null vs any code | toggles final score/band |
| Duplicate detector fires twice | same code twice | deduped list length 1 |
| Override + `not_analyzable` | illegal upstream combo | define precedence — normally pipeline stops earlier |

## Test intent (Rule 9)

This ticket guards **R-06-4** in [[EPIC-06-rubric-engine]]: averages cannot bury absolute nullities — tests compare green-path aggregate vs overridden outcome on identical numeric inputs.

# CS-005 — Pre-commit hooks for **`backend/`** + **`frontend/`**

## Context

Local hooks catch formatting and lint issues before CI spend. This ticket wires a single pre-commit entry point that respects both Python and Node toolchains introduced in [[CS-002]] and [[CS-003]].

## Scope

**In:**

- `pre-commit` configuration at repo root invoking **`ruff` (lint + autofix scoped to `backend/`)**. CI still drives **Black** + **isort**; **`ruff format` stays out of hooks** so we avoid mass rewriting the Python tree whenever pre-commit reruns broadly.
- **Prettier** (`prettier@3.8.3`, `--check` only via an isolated **`language: node`** env) scoped to **`frontend/**/*.{ts,tsx,js,jsx,json,md}`**
- Lightweight hygiene hooks (`trailing-whitespace`, `merge-conflict`, YAML/TOML checks) plus **`end-of-file-fixer`** with excludes for `docs/`, `frontend/public/`, `.cursor/rules/`
- Onboarding snippet in root **`README.md`** (`pip install pre-commit`, `pre-commit install`, optional `run --all-files`)

**Out (explicit):**

- Custom policy engines beyond format/lint
- Secret scanning replacement for `.env` hygiene — covered by developer discipline + [[CS-006]]

## Acceptance criteria

- [x] Given hooks installed per docs, when a developer commits a Python file with a ruff violation, then the commit is blocked with a fixable message
- [x] Given hooks installed, when a developer commits a TS/TSX file with a deliberate Prettier drift, then the commit is blocked (**`prettier --check`**) consistent with CI
- [x] Given hooks installed, when only Markdown under `Projects/` changes, when the commit includes no Python/TS, then hook set completes quickly (heavy hooks scoped by `files:` filters per hook)
- [x] Given `pre-commit run --all-files`, when executed on clean tree after [[CS-004]] baseline, then the command exits zero (**verified 2026-05-17**; exclusions documented inline + in `README`)

## Test intent (Rule 9)

Pre-commit encodes “same author voice” across the monorepo. It must fail when someone bypasses the lint rules that CI will enforce anyway, preserving review focus for behavior not style.

## Notes

- Align **`ruff`** with `backend/pyproject.toml` dev pins. **mypy** + **Vitest**/Playwright deliberately stay CI-only paths (latency / resolver constraints).
- If hook runtime becomes painful, tighten `files:/exclude:` tuples instead of weakening CI parity.

# CS-202 — Render overall verdict score, band, and override box

## Context

Readers must grasp the disposition within seconds ([[PRD_F6_GENERACION_REPORTE]] §3 US-03). The verdict section aggregates numeric score, color band semantics, synthesized summary, and a forced attention override treatment when rubric overrides fire ([[RUBRICA_CONTRATO]] §11.1 Section 2).

## Scope

**In:**
- Large numeric display of `score_total` in 0.0–10.0 with one decimal where applicable, matching stored band
- Color tokens: green `#10B981`, yellow `#F59E0B`, red `#EF4444` with paired icon+text labels (Favorable / Negocia antes de firmar / Procede con cuidado) per §3 US-03 — **never color alone** (labels + emoji icons per §3 US-03)
- `executive_summary` text block from pipeline output (`ContractAnalysis`/synthesis artifact)
- When `override_triggered` non-empty: bordered red "**Hallazgo crítico**" panel listing codes + descriptive copy drawn from authoritative override texts, plus fixed warning paragraph from §3 US-03

**Out (explicit):**
- Recalculating score from criteria (consumes persisted engine output only)
- Category-level breakdown (lives in [[CS-204]])
- Economic figures (CS-203)

## Acceptance criteria

- [ ] Given fixture with `band=green`, rendered HTML exposes score typography class distinct from yellow/red variants and textual label "**Favorable**" beside icon semantics from §3 US-03 (no reliance on hue alone — screen reader/name includes band text)
- [ ] Given overrides list `["...", "..."]`, section renders unordered list tying each entry to readable description surfaced from rubric catalog constant or DB row loaded by stable code (not raw codes alone)
- [ ] Given edge scores {4.9,5.0,7.9,8.0} paired with bands matching engine output, visual treatment matches the band label associated with stored `band` (display defers to persisted band to avoid duplicate policy logic)
- [ ] Given high-contrast mode flag in HTML snapshot tests (or forced-colors media query stylesheet hook), foreground/background deltas remain perceptible ([[PRD_F6_GENERACION_REPORTE]] §3 US-03 high-contrast bullet)

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| Overrides | Empty array vs ≥1 entries | Empty: normal verdict only; ≥1: red override panel MUST appear ahead of tertiary marketing copy |
| `override_triggered` length | Single vs multiple codes | Multiple: each enumerated without collapsing |

## Test intent (Rule 9)

Overrides forcibly degrade user trust semantics independent of averaged score ([[EPIC-06-rubric-engine]] posture); omission of the critical override panel despite non-empty overrides is worse than cosmetic drift and must flip tests focused on juridical safety messaging.

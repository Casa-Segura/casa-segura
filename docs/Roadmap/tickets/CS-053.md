# CS-053 — Extract text from text-layer PDFs with pypdf

## Context

Text-layer PDFs should extract **without** vision spend. [[PRD_F1_INGESTA_Y_OCR]] §US-05 mandates pypdf iteration, page separators, normalization, token counting, short-text fallback to vision, and a **30s** hard timeout.

## Scope

**In:**

- `pypdf` full-document extraction for files classified as text PDFs ([[CS-052]]).
- Concatenate pages with `\n\n--- PAGE N ---\n\n` separators exactly as PRD.
- Normalize whitespace and strip non-printable control characters while preserving meaningful newlines.
- Estimate tokens with `tiktoken` `cl100k_base` into `ContractSubmission.extracted_text_token_count` (count only; **no text persisted** per [[PRD_F1_INGESTA_Y_OCR]] BR-02 / [[DOMAIN_MODEL]] §4.1).
- If total extracted characters **after normalization < 500**, mark failure path that **schedules vision retry** per [[PRD_F1_INGESTA_Y_OCR]] §US-05 and BR-08.
- Enforce **30 second** wall-clock timeout → failed job with explicit `TIMEOUT` / strategy failure code feeding [[CS-056]] envelopes.
- Create/update `OcrJob` rows: `strategy=pypdf`, `tokens_consumed=0`, `cost_estimate_cents=0`, `status=success|failed|timeout`.

**Out (explicit):**

- Vision LLM invocation — [[CS-054]].
- Language detection — handled where pipeline defines (see [[CS-056]] coupling).

## Acceptance criteria

- [ ] Given a synthetic PDF fixture with stable known text spanning **3 pages**, when extracted, then output contains **`--- PAGE 1 ---` … `PAGE 3`** markers in order without missing pages.
- [ ] Given extracted text totaling **499** characters post-normalization, when pypdf completes, then the orchestrator transitions to vision strategy attempt and records pypdf as insufficient (not “success end state”).
- [ ] Given extraction exceeding **30 seconds** (simulate with stall hook in test), when watchdog fires, then `OcrJob.status` records timeout and user-facing path surfaces `not_analyzable` / technical code per failure policy ([[CS-056]]).
- [ ] Given successful extraction, when persisted fields are written, then **no column** stores raw extracted text; only counts and statuses exist.
- [ ] Golden test: normalized output matches expected snapshot for whitespace/control-char edge cases (NBSP, `\r\n`, soft hyphen).

### BVA — boundary value analysis

| Measure | Boundary | Expected |
|---|---|---|
| Post-normalization char count | 499 / 500 / 501 | <500 triggers vision retry per PRD; ≥500 allows success if other gates pass |
| Timeout | 29.9s / 30.0s | At boundary, define inclusive policy in code + test (avoid flaky tests) |
| Pages | 1 / max allowed (50 per PRD per file gate) | Linear time behavior documented; failures surfaced before pypdf when page count rejects at [[CS-059]] |

## Test intent (Rule 9)

The **500-character minimum** is an OCR-quality sentinel; tests must fail if someone “optimizes away” the retry and lets garbage text reach classification ([[PRD_F1_INGESTA_Y_OCR]] BR-08).

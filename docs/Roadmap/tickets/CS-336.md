# CS-336 — User-facing error / discrepancy report channel

## Context

Product open question #8 asks how users report **analysis discrepancies** (misidentified findings, missing citations). This ticket defines a **minimal, privacy-preserving** channel: structured form or mailto with guidance, **no** contract upload in the report flow, and operational handling notes.

## Scope

**In:**
- Public page or modal reachable from report footer (copy references same route key as F6 footer hook when built)
- Collects: `public_short_id` (optional), free-text description, contact email **optional** with consent checkbox, category enum (classification, citation, economic figure, UI)
- **Rate limits** per IP + per short id to deter spam (see BVA)
- Ticketing destination (GitHub private security flow vs helpdesk inbox) chosen and documented
- PII minimization: warn users not to paste contract text; client-side length cap

**Out (explicit):**
- Guarantee of individual legal review outcome or SLA to user
- Automatic reanalysis from report text

## Acceptance criteria

- [ ] From UI, user can submit a report without executing contract analysis (static route)
- [ ] Submissions store only fields above; **no** attachment of PDFs/images in v1
- [ ] Rate limit returns `429` with Retry-After; logs per [[CS-331]] carry no submission body beyond bounded length hash for dedupe
- [ ] Operator runbook: triage labels, when to open engineering ticket vs close as user education
- [ ] Link from `SECURITY.md` / PRD question #8 cross-references this channel

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| Reports / IP / hour | at limit vs limit+1 | 429 with stable error schema |
| `public_short_id` format | valid `CS-YYYY-XXXXXX` vs garbage | accepted with tag `unverified_id` |
| Text length | max-1 vs max chars | longer rejected before persistence |
| Optional email | blank vs provided | blank path still creates ticket without PII storage beyond transient queue |

## Test intent (Rule 9)

Tests must show the channel advances **open question #8** without turning into **BR-01** violation (accidental contract storage); rate limits protect ops without blocking legitimate single reports.

# CS-082 — Implement tag and relevance normalization rules

## Context

Filtering by tags lowers false positives prior to pgvector scans. Epic overview + [[FEATURES_MAP]] cite rule-based tagging (compraventa, arrendamiento, plazo, fideicomiso, consumidor, etc.). BR-08 in [[PRD_F3_CORPUS_Y_RAG]] orders lowercase accent-stripped canonical tags across corpus + queries.

## Scope

**In:**

- Normalization helper `normalize_tag(text) -> slug` enforcing BR-08 (Spanish accents removed, punctuation collapsed).
- Combine explicit YAML `tags:` with inline chunk tag lines surfaced by parser.
- Maintain optional `relevance_for_findings` mapping from headings / metadata lines (`Relevant_for:` / rubric criterion hints) strictly as **strings** devoid of hallucinated synonyms.
- Golden tests covering Spanish diacritics (`arrendamiento` vs `ARRENDAMIENTO`).
- Persistence contract: Postgres `TEXT[]` columns indexed via GIN per [[DOMAIN_MODEL]] §3.6.

**Out:**

- ML-based tag augmentation.

## Acceptance criteria

- [ ] Given input `"Compr á venta"` (malformed spacing), normalization yields stable canonical token `compra-venta` or `compraventa` — **pick one documented scheme** consistent across ingestion + retrieval filters ([[PRD_F3_CORPUS_Y_RAG]] BR-08).
- [ ] Given duplicate synonyms in source (`fsv`,`ley-fsv`), dedupe while preserving deterministic ordering lexicographically.
- [ ] Given ingestion pipeline run, malformed tag strings raise validator error (`illegal character`) rather than silently dropping.
- [ ] Query-time filter duplicates normalized tags identical to ingestion path via shared library function (integration test verifying roundtrip).

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| Empty tag list vs single tag vs 32 tags array | cardinality | Respect Postgres index practical limits (~100) by warning when >threshold |

## Test intent (Rule 9)

Normalization tests protect **consistent pre-filter semantics** — mis-normalizing tags breaks retrieval guardrails independently of embeddings.

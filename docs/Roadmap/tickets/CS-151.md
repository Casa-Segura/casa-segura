# CS-151 — Implement OverrideCode catalog with legal anchors

## Context

Eleven critical overrides force `score_total = 0` and `band = red` regardless of weighted averages ([[RUBRICA_CONTRATO]] §2.2, [[PRD_GENERAL]] US-03). They must be first-class constants with stable codes shared by evaluators, aggregation, and telemetry ([[PRD_F4_MOTOR_RUBRICA]] US-02).

## Scope

**In:**
- Enum / constant module `OverrideCode` with exactly eleven members: `art_1605_cc`, `art_1613_cc`, `art_1644_cc`, `art_1425_cc`, `art_3_ivu_family_homestead`, `art_5_lpc_non_waivable`, `art_12_lpc`, `art_13_lpc`, `art_18_lpc_blank_signature`, `art_17h_lpc_arbitration`, `art_58_fsv`
- Per-code metadata: human-readable title (Spanish), primary legal anchor strings for F3 `prefer_anchors`, associated criterion id(s) from [[RUBRICA_CONTRATO]] §16 appendix where applicable

**Out (explicit):**
- LLM prompts for detection — criterion tickets / [[CS-158]]
- Persistence migration — [[EPIC-01-persistence]]

## Acceptance criteria

- [ ] Given code review against [[RUBRICA_CONTRATO]] §2.2 and [[PRD_F4_MOTOR_RUBRICA]] US-02 table, the set of eleven codes matches **exactly** (no aliases, no omissions)
- [ ] Given each `OverrideCode`, `associated_criterion_ids` includes at least the criterion listed in PRD_F4 (e.g. `art_12_lpc` → `B7`)
- [ ] Given application import of the catalog, duplicate string values are impossible (single enum source of truth)
- [ ] Given telemetry hook placeholder, each code maps to a stable snake_case metric label ≤64 chars

### BVA — boundary value analysis

| Input | Boundary | Expected |
|---|---|---|
| String coercion | unknown code `"art_99_cc"` | rejected at parse / unknown handling explicit |
| Serialization | enum → JSON → enum | round-trip stable |
| Associated criteria | empty list for any override | forbidden — every override maps to ≥1 criterion |
| Display title | empty string | validation fails |

## Test intent (Rule 9)

If product adds a twelfth override in [[RUBRICA_CONTRATO]] without updating this catalog, tests must fail loudly — overrides are **hard gates** on user-facing band, not cosmetic labels.

# CS-209 — Convert report HTML to PDF with WeasyPrint

## Context

Operators and purchasers archive via PDF while HTML remains authoritative layout source ([[PRD_F6_GENERACION_REPORTE]] §3 US-09). Renderer must faithfully mirror responsive intent at print density via WeasyPrint per stack table §6.

## Scope

**In:**
- `generate_report_pdf(analysis_id, options)` wraps `generate_report_html` pipeline then WeasyPrint render
- Configurable **page size** `Letter | A4` via `REPORT_PDF_PAGE_SIZE` default Letter; margins `REPORT_PDF_MARGIN_CM` default `1.5`
- Pagination chrome: repeating header strip with analysis id (`public_short_id`) distinct from body hero header; page numbering in footer per §3 US-09
- Subtle watermark using embedded Casa Segura logo bytes (already present for HTML) inlined for print (no remote fetch per BR-14)
- Telemetry hooks: elapsed ms + byte length returned to orchestrator (`bytes_generated`)

**Out (explicit):**
- Persisting PDF artifacts to blob storage / DB (`BR-01`)
- Fallback email strategy when failing (implemented in delivery epic per open question §10 Q1 and [[PRD_F7_ENTREGA_MULTICANAL]] integration)

## Acceptance criteria

- [ ] Given representative golden analysis fixtures, median PDF payload `< 1_000_000` bytes (`1 MB`) cold run on CI reference hardware ± documented tolerance slack
- [ ] Given same fixture sequential invocation, converter completes median `<5000 ms` wall clock on CI reference hardware (document machine profile) aligning with §3 US-09 SLO baseline
- [ ] Failure path returns enumerated error `{code:'PDF_RENDER_FAILED', detail}` without partial file persistence
- [ ] Fonts remain embedded subsets; verifying `pdffonts` analog or library introspection asserts no unresolved remote font pipelines

### BVA — boundary value analysis

| Metric | Boundary | Expected |
|---|---|---|
| PDF bytes `B` vs cap | ≤999,999 vs ≥1,000,000 | At cap breach emit metric + escalate product review (fixture catalog update) rather than silently compress lossy |
| Page size enum | Letter vs A4 | Switch modifies CSS `@page size` honoring margin constant |
| Runtime | `<5000 ms` vs `≥5000 ms` regression | Alerting threshold flagged in dashboards (non-blocking MVP) |

## Test intent (Rule 9)

WeasyPrint upgrades can regress pagination causing clauses to omit — snapshot compare of page count/hash for golden fixture anchors compliance with BR-05 partial reproduction limits (only cited clauses printed, not bulk contract dump).

## Notes

- Maintain parity with disclaimers/header/footer interplay from HTML (no divergence of legal copy)
- If watermark harms readability, adjust opacity under design review documenting contrast ratio unaffected

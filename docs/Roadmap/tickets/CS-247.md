# CS-247 — On-demand report regeneration port (no persistence)

## Context

Web link + internal channels must reuse the same non-persistent HTML synthesis entrypoint mandated by BR-01 ([[PRD_F7_ENTREGA_MULTICANAL]] §6.1, [[PRD_GENERAL]]).

## Scope

**In:**
- Python service function `generate_report_html_for_analysis(analysis_uuid | public_short_id, …)` invoking F6 package produced in [[EPIC-07-report-generation]]
- Guards mirroring §3 readiness (reject pending/failed/not found; anonymized path per F6 §3 US-08)
- Optional compression (`gzip`) **off** for MVP simplicity — deliver raw HTML to stay debuggable unless perf ticket requests
- Returns `(html:str, diagnostics:RenderStats)` for metrics (ms, size)

**Out (explicit):**
- PDF generation (CS-209)
- Storing render output in object storage

## Acceptance criteria

- [x] Double invocation in same request context does not write files under `/tmp` surviving process (tmp cleanup or in-memory only)
- [x] When analysis missing, raises `ReportNotFound` consumed by HTTP layer as 404
- [x] HTML size logging at INFO level records byte length but **no** content snippets > N chars

### BVA — boundary value analysis

| State | Boundary | Expected |
|---|---|---|
| Analysis `completed` vs `pending` | flag | pending raises `AnalysisNotReady` mapped to user-safe error |
| Anonymization | anonymized fixture | degraded HTML per CS-200 dual template path |

## Test intent (Rule 9)

Accidental caching layer writing HTML to disk violates BR-01 even if ephemeral — filesystem assertion after call must prove cleanliness.

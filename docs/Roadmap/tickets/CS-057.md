# CS-057 — Enforce discard-after-extract invariant with tests

## Context

Privacy architecture requires **never persisting uploaded contracts or OCR text**. [[PRD_GENERAL]] BR-01 and [[PRD_F1_INGESTA_Y_OCR]] §US-10 / BR-01–BR-02 forbid writing originals to disk or DB columns holding extracted plaintext; transient Redis blobs must TTL **≤300s** and explicit delete paths.

## Scope

**In:**

- Implementation audit: grep/mypy/ci script ensuring no `LegalDocument/UserUpload` mismatches — contract bytes only in memory/`bytesio`/`Redis` with TTL cap.
- Ensure temp files (**if pdf2image or converters require FS**) reside on `tempfile`-backed directories with **`delete=True`** finalize hooks and teardown on exceptions.
- Automated test (can be nightly) scanning configured volume paths for stray `pdf/png` patterns after integration test uploads (stubbed FS acceptable if Docker).
- Observability checks: Prometheus/log-based assertion that decryption keys for user blobs never persisted.
- Document operational procedure for engineers: “never enable debug raw dumps in prod configs.”

**Out (explicit):**

- Legal corpus files on disk (`RAG Legal context/`) — curated public content, unrelated to user uploads.

## Acceptance criteria

- [ ] Given a successful OCR path, when processing completes or fails terminally, then **no persisted row** stores raw file bytes nor full extracted strings (validated by schema asserts + regression test scanning Django model fields declared in ingestion-related apps).
- [ ] Given Redis staging is used between workers, when job ends, then Redis keys are **explicitly DEL** plus TTL ≤ **300s** enforced at connection policy layer.
- [ ] Given converters create temp files during tests, when context managers exit, then filesystem contains **zero** lingering temp artifacts (platform-safe best effort).
- [ ] CI gate fails if new migration adds forbidden columns (`extracted_text`, `file_blob`, etc.) flagged by reviewer-maintained denylist matcher.

### BVA — boundary value analysis

Skip dedicated table — boolean invariant ticket. Temporal boundary: TTL **299s vs 300s** enforced at config parsing with test double.

## Test intent (Rule 9)

This ticket’s tests encode **privacy non-regression**, not OCR accuracy — altering storage policy must break CI even if OCR “works.”
